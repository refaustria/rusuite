# Write quality pass, October 2026 (P8-38)

Exploratory test of every Write feature listed in [ui.md](../ui.md) (Write sections) and [write-layout.md](../write-layout.md)
against Word's behaviour: Playwright scripts (headless Chromium, 1400 × 900 and 1024 × 768, English and German UI) drove
the web build through the journeys of the task brief, with a screenshot per step (`shots/P8-38-*.png` in the task's
worktree, not committed). Regression tests: `packages/e2e/tests/write-qa.spec.ts` (one test per fixed item or group) and
unit tests next to the code (`undo_groups.rs`, `tests/write.rs`, `plainPaste.test.ts`, `paragraphDialog.test.ts`, the
`W-nn` cases in `SyncPlugin.test.ts`, `tableCommands.test.ts`, `StructureUi.test.tsx`, `WriteBatch.test.tsx`,
`ribbon.test.tsx`).

**Result: 30 findings, no blocker** – major 17 (17 fixed, 0 deferred), minor 9 (4 fixed, 5 deferred), cosmetic 4 (3 fixed, 1 deferred).
