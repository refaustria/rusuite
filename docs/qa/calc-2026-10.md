# Calc quality pass, October 2026 (P8-39)

Exploratory test of every Calc feature listed in [ui.md](../ui.md) (Calc sections), [functions.md](../functions.md),
[number-formats.md](../number-formats.md), [charts.md](../charts.md), [pivot.md](../pivot.md) and
[shortcuts.md](../shortcuts.md) against Excel's behaviour: Playwright scripts (headless Chromium, 1400 × 900 and
1024 × 768, English and German UI) drove the web build through the journeys of the task brief, with a screenshot per step
(`shots/P8-39-*.png` in the task's worktree, not committed). Displayed values were read from the print preview's HTML and,
after C-01, from the system clipboard. Regression tests: `packages/e2e/tests/calc-qa.spec.ts` (one test per fixed item or
group) and unit tests next to the code (`engine_formula::entry` tests, `rename_sheet_rewrites_formula_text`,
`model_sheet::numfmt` `edit_input_forms`, `fill.rs` `weekday_and_month_lists`, `tests/calc.rs`
`typed_entries_get_excel_formats`, `helpers.test.ts`, `numberFormat.test.ts`).

**Result: 23 findings, no blocker** – major 8 (6 fixed, 2 deferred), minor 13 (7 fixed, 6 deferred), cosmetic 2 (2 fixed).

Note for the build: the prebuilt `apps/calc/src-wasm/pkg` of the main checkout (11:15) predated the P8-35 merge, so a
copied web build opened `provisional-tables.xlsx` without its tables and structured references ("not supported"
warnings). With a fresh `pnpm build:wasm` everything below was retested; this is not a defect of the app.
