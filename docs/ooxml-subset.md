# OOXML Subset

Which parts and elements of Office Open XML (ECMA-376, transitional) Rusuite reads and writes, per
format, and where it is knowingly lossy. Scope rules are in the README; the crate layout is in
[architecture.md](architecture.md).

Common to all three formats (`fmt-ooxml`):

- **Package.** ZIP container, `[Content_Types].xml` (Default + Override), package and part relationships,
  OPC part-name rules. The main part is found through the `officeDocument` relationship (transitional or
  Strict URI).
- **Reading** is tolerant: elements and attributes are matched by local name (any namespace prefix);
  content outside the subset is dropped with a warning in `ReadOutput.warnings`, never silently.
- **Writing** regenerates every part from the model with the standard declaration
  (`standalone="yes"`) and deterministic output; characters XML 1.0 cannot carry are dropped (SpreadsheetML
  text keeps them as `_xHHHH_`). Relationship and content types come from `fmt_ooxml::{rel, ct}`.
- **Theme** (`*/theme/theme1.xml`, `fmt_ooxml::theme`): color scheme (`a:srgbClr`, `a:sysClr/@lastClr`)
  and major/minor fonts are read into `core_model::Theme`; format/effect styles are not modelled
  (except by Show, see the pptx section). Each
  writer can put the imported theme part back verbatim (conditions per format below); otherwise it emits a
  minimal Office-like theme (Word: `dk1`/`lt1` as `a:sysClr`; Show: generated from the model's theme).
- **Charts** (`*/charts/chartN.xml`, `fmt_ooxml::chart`): `c:chartSpace` ↔ `core_model::chart::Chart`
  (P8-18, used by xlsx; meant for pptx/docx charts too). The mapping is listed under xlsx below;
  caches are written from a `ChartData` source (Calc: the workbook), else from the model.
- **docProps** (`core.xml`, `app.xml`) are ignored on read and written minimal by xlsx and pptx; docx reads and writes
  the core properties and the page count (P8-27, see the docx section).
  (P8-18; used by xlsx and, since P8-24, pptx). The mapping is listed under xlsx below;
  caches are written from a `ChartData` source (Calc: the workbook; Show: the chart's table), else
  from the model. `read_chart_ext` / `write_chart_with` (pptx) keep `c:externalData r:id` (the
  embedded workbook, `c:autoUpdate val="0"`) and can write a transparent chart area (`c:spPr`
  `a:noFill` + `a:ln/a:noFill`); `read_chart` / `write_chart` (xlsx) are unchanged.
- **docProps** (`core.xml`, `app.xml`) are ignored on read and written minimal.

## xlsx (`fmt-xlsx`)

`fmt_xlsx::read(&[u8]) -> Workbook` and `fmt_xlsx::write(&Workbook) -> Vec<u8>` (plus
`read_with_warnings`, `read_with_context` / `write_with_context`, and native-only `read_path` /
`write_path`). The crate compiles for `wasm32-unknown-unknown`. Transitional SpreadsheetML only.

### Read

| Part / element | Handling |
|---|---|
| `xl/workbook.xml` `<sheets>` | Order, names, `r:id` → worksheet part via relationships. A `<sheet>` that targets a chartsheet/dialog sheet is dropped (warning). `state="hidden"` / `"veryHidden"` → `hidden` / `very_hidden` sheet flags (applied after loading; if every sheet is hidden, the last one is shown, warning). |
| `workbookPr date1904="1"` | `Error::Unsupported("date1904")`. |
| `<definedNames>` | Every `<definedName>` → `DefinedName` (P8-23) in file order: `name`, `localSheetId` (index into `<sheets>`; absent = workbook scope), `hidden`, `comment`, the text as the definition (`_xlfn.` prefixes stripped, `Sheet1!#REF!` read as `#REF!`, a top-level union `A,B` kept). `_xlnm.Print_Area`, `_xlnm.Print_Titles`, `_xlnm.Criteria`, `_xlnm.Extract`, `_xlnm.Consolidate_Area`, `_xlnm.Sheet_Title` → built-in names shown as `Print_Area` …; the print area and titles of a sheet are its built-in names (`Workbook::print_area` / `print_titles`). Names are defined before the cells are loaded, so formulas using them get their dependency edges. Skipped silently: `_xlnm._FilterDatabase` (the AutoFilter is read from the sheet) and Excel's `_xlfn.*` placeholder names. A name whose sheet is missing, that is not a valid name, or whose text the formula grammar cannot read (external references `[1]Sheet1!A1`) is dropped with a warning. |
| `xl/sharedStrings.xml` | `<si><t>` and rich text `<si><r><t>` (runs concatenated, run formatting dropped, phonetic `<rPh>` skipped). `_xHHHH_` escapes decoded. |
| `xl/styles.xml` `<numFmts>` | id → code. Built-in ids map through `model_sheet::numfmt::builtin_code`: ids 0–49 (the locale-dependent currency 5–8 and accounting 41–44 as Excel's en-US codes; the East-Asian 23–36 and 50–58 as `General` / `m/d/yyyy` / `h:mm:ss` aliases, read-only). Unknown ids read as General (warning). Any code equal to `General` (case-insensitive) → `None`. Every code is displayed with the full format grammar (`docs/number-formats.md`). |
| `<fonts>` | `name`, `sz`, `b`, `i`, `u` (`single`/`double`, accounting variants mapped), `strike`, `vertAlign`, `color`. Font 0 is the workbook default font (kept in `XlsxContext.default_font`); every cell font is stored as the **difference** from font 0 (a bold Arial-10 font in an Arial-10 workbook reads as `bold: Some(true)`). `family`, `scheme`, `charset`, `outline`, `shadow`, `condense`, `extend` dropped. |
| `<fills>` | `patternFill solid` → `Fill::Solid(fgColor)`; `none`/`gray125`/missing → `None`; other patterns → solid with the foreground color, gradients → `None` (one warning). |
| `<borders>` | `left`/`right`/`top`/`bottom` (also `start`/`end`) style + color (missing color → `Color::Auto`). `thin medium thick dashed dotted double hair` map 1:1; `mediumDashed`, `dashDot`, `mediumDashDot`, `dashDotDot`, `mediumDashDotDot`, `slantDashDot` → `Dashed`. Diagonals dropped. |
| colors | `rgb` → `Color::Rgb` (alpha ignored); `theme="N" tint` → `Color::Theme { slot, tint }` (index order `lt1 dk1 lt2 dk2 accent1..6 hlink folHlink`; never resolved to RGB); `indexed` → legacy 64-color palette (or the file's `<indexedColors>`), 64/65 → `Auto`; `auto="1"` → `Auto`. |
| `<cellXfs>` | `numFmtId`/`fontId`/`fillId`/`borderId` taken as given (`applyX` flags ignored, as Excel does); `<alignment horizontal vertical wrapText indent>` (`centerContinuous` → center, `distributed` → justify; vertical `justify`/`distributed` → center). Default values (`general`, `bottom`, `wrapText="0"`, `indent="0"`) read as `None`. `textRotation`, `shrinkToFit`, `<protection>` dropped. Each xf is interned into the `StyleTable`. |
| `<cellStyleXfs>`, `<cellStyles>`, `<tableStyles>` | Ignored (named styles are not modelled). |
| `<dxfs><dxf>` | Differential formats of conditional formatting → `DxfStyle`: `<font>` `b`/`i`/`strike` (with `val`), `u` (any but `none` = on), `color`; `<numFmt formatCode>` (or a built-in `numFmtId`); `<fill><patternFill>` → solid fill with `bgColor` (Excel's dxf convention), else `fgColor`, `patternType="none"` → none; `<border>` sides as for cell borders. `alignment`/`protection` dropped silently. Colors resolve against the file's palette. |
| `xl/theme/theme1.xml` | `<a:clrScheme>` parsed into `XlsxContext.color_scheme`; the raw part is kept in `XlsxContext.theme_xml` and written back verbatim by `write_with_context`. |
| `<sheetFormatPr>` | `defaultColWidth`, `defaultRowHeight` → `SheetFormat` (absent `defaultColWidth` → 8.43). |
| `<cols><col>` | `min..max` expanded per column: `width` (if `customWidth="1"`, or if `customWidth` is absent and the width differs from the sheet default), `hidden`, `style`. |
| `<row>` | `ht` only with `customHeight="1"` (otherwise it is a cached auto height), `hidden`, `s` only with `customFormat="1"`. Missing `r` = previous row + 1. |
| `<c>` | `t="s"` shared string, `t="str"`/`t="inlineStr"` text, `t="b"`, `t="e"` (`#SPILL!` and `#CALC!` are errors; unknown error codes such as `#BLOCKED!` → text, warning), `t="n"`/absent → number, `t="d"` → text (warning). Missing `r` = next column. Text constants are stored as `Value::Text` (never re-parsed: `"0123"` stays text). A cell with only `s` is a style-only cell. |
| `<f>` | Input = `"=" + text` with `_xlfn.`/`_xlws.` prefixes stripped; the engine recomputes, the cached `<v>` is ignored. Shared formulas: the master (`t="shared" ref si` with text) is parsed, dependents (`si` only) get `offset_relative(master, Δrow, Δcol)` (canonical text). `t="array"` (dynamic arrays with `<c cm>` as well as legacy CSE arrays) → a spilling formula in the top-left cell; the other cells of its `ref` hold cached spill values and are not loaded (their styles are). `_xlfn.ANCHORARRAY(x)` → `x#`, `_xlfn.SINGLE(x)` → `@x` (formula text regenerated). Plain formulas get `@` where legacy Excel intersected implicitly: on multi-cell references, range expressions, multi-element array constants and calls of `TRANSPOSE`, `SORT`, `SORTBY`, `FILTER`, `UNIQUE`, `SEQUENCE`, `RANDARRAY` that are the formula's value or operands of operators (`A1:A3*2` → `@A1:A3*2`; function arguments are unchanged). `t="dataTable"` and formulas the engine cannot parse → the cached value is kept as a constant (warning). |
| `<sheetViews>` | First `<sheetView>` only: `showGridLines`, `showRowColHeaders`, `zoomScale` (clamped to 10..=400; absent/0 → 100) → `SheetView`. `<pane state="frozen">` / `"frozenSplit"` → `frozen_rows = ySplit`, `frozen_cols = xSplit` (`topLeftCell`, `activePane` ignored); a split pane (no/other `state`) is dropped (warning "split panes dropped"). `tabSelected`, `<selection>`, further views ignored. |
| `<autoFilter ref>` | → `Workbook::set_auto_filter` (range, header row first). `<filterColumn colId>` (relative to the range): `<filters blank><filter val>` → `Filter::Values` (`blank="1"` → the entry `""`); `<customFilters and><customFilter operator val>` → `Filter::Custom` (`equal`/`notEqual` patterns `*x*`, `x*`, `*x` with a literal `x` → `Contains`/`NotContains`, `BeginsWith`, `EndsWith`; `~` escapes undone); `<top10 top percent val>` → `Filter::Top10` (`filterVal` ignored); `<dynamicFilter type>` `aboveAverage`/`belowAverage`/`today`/`yesterday`/`tomorrow` → `Filter::Dynamic`. Date groups (`dateGroupItem`), colour/icon filters and other dynamic types drop that column (warning); columns outside the range are dropped (warning). With at least one column filter, the hidden rows of the range (`hidden="1"`) are marked `filtered` (the file does not distinguish rows hidden by hand). `sheetPr filterMode`, `hiddenButton`/`showButton` ignored. |
| `<sortState ref caseSensitive>` | At sheet level or inside `<autoFilter>` → `SortState`; `<sortCondition ref descending>` → one key (column of `ref`). Conditions with `sortBy` other than `value` (colour, icon) are dropped (warning); `customList` ignored. |
| `<mergeCells><mergeCell ref>` | → `Workbook::add_merge` (contents of the covered cells are kept as in the file). Single cells, malformed refs and ranges overlapping an earlier merge are dropped (one warning listing them). |
| `<conditionalFormatting sqref><cfRule>` | → `Workbook::add_cf_rule` per rule, ordered by `priority` across all elements (ties in document order), renumbered `1..`; `sqref` (space-separated ranges) → `ranges`; `dxfId` → the `<dxf>`; `stopIfTrue`. Types: `cellIs` (`operator`, 1–2 `<formula>`), `expression`, `containsText`/`notContainsText`/`beginsWith`/`endsWith` (the `text` attribute; the stored formula is ignored), `containsBlanks`, `notContainsBlanks`, `containsErrors`, `notContainsErrors`, `top10` (`rank percent bottom`), `aboveAverage` (`aboveAverage equalAverage`; `stdDev` ignored, warning), `duplicateValues`, `uniqueValues`, `dataBar` (2 `<cfvo>` + `<color>`, `showValue`; `minLength`/`maxLength` ignored), `colorScale` (2–3 `<cfvo>` + as many `<color>`s), `iconSet` (the 17 Excel 2007 sets, `reverse`, `showValue`; `gte="0"` read as `>=`, warning). `<cfvo type>` `min`/`max` (also x14 `autoMin`/`autoMax`), `num`, `percent`, `percentile`, `formula` with `val`. Formulas: `_xlfn.` stripped, relative to the top-left cell of the ranges' bounding box. Other types (`timePeriod`, …), unknown `dxfId`s, unparsable formulas and invalid `sqref`s drop the rule (warning). A `<cfRule><extLst>` (Excel 2010 data bar extension) is ignored. |
| `<dataValidations><dataValidation>` | → `Workbook::set_validation` (a later validation wins on overlapping cells). `type` `none` → `Any`, `list`, `whole`, `decimal`, `date`, `time`, `textLength` (`operator`, default `between`; `formula2` for `between`/`notBetween`), `custom`; a list `formula1` in double quotes (`"a,b,c"`, `""` = `"`) → `Literal` values split at `,`, otherwise → `Formula`. `allowBlank`, `showDropDown` (inverted: `1` hides the dropdown), `showInputMessage`, `showErrorMessage`, `errorStyle` (`stop`/`warning`/`information`), `errorTitle`, `error`, `promptTitle`, `prompt`. Absent flags read as false. Malformed validations are dropped (warning). `imeMode` ignored. |
| Worksheet `<extLst>` | `x14:dataValidations` (Excel 2010 list sources on other sheets, `<x14:formula1><xm:f>` and `<xm:sqref>`) are read like `<dataValidation>`s (warning: saved as standard data validation). `x14:conditionalFormattings` (data bar extensions, x14-only icon sets and rules) are dropped (one warning with the rule count). Other extensions are ignored silently. |
| `<drawing r:id>` → `xl/drawings/drawingN.xml` | Charts (P8-18): every `xdr:twoCellAnchor` (`from`/`to` cell + EMU offset), `xdr:oneCellAnchor` (`from` + `ext`) and `xdr:absoluteAnchor` (`pos` + `ext`) holding a `xdr:graphicFrame` with `c:chart r:id` → a `ChartObject` (`cNvPr/@name` kept, ids `1..` in document order, anchors' `editAs` ignored). Pictures, shapes, connectors, groups and other graphic frames are dropped (one warning per kind and sheet). The chart part is read by `fmt_ooxml::chart` (below); its Office 2013 `chartStyle`/`chartColorStyle` parts are consumed silently, other chart relationships (user shapes, embedded data) are dropped. Reference caches are dropped when the reference resolves in the workbook (Calc recomputes them) and kept otherwise. |
| `xl/charts/chartN.xml` (`fmt_ooxml::chart`) | Chart groups `barChart` (`barDir`, `grouping`, `gapWidth`, `overlap`), `lineChart` (`grouping`, `marker`), `areaChart`, `pieChart` / `doughnutChart` (`firstSliceAng`, `holeSize`; 50 % reads as default), `scatterChart` (`scatterStyle`; lines/markers/smoothing folded from the series as Excel's chart types do), `varyColors`; several groups → `Combo` with per-series kinds; a group whose value axis is not the first group's → secondary axis. Any other group (radar, stock, bubble, surface, 3-D, of-pie) → `ChartKind::Unsupported` with the whole part kept as XML (minus `c:userShapes`/`c:externalData`), warning. `c:ser`: `tx` (`strRef` with cache, `v`), `cat`/`val`, `xVal`/`yVal` (`numRef`/`strRef` with `f` and cache, `numLit`/`strLit`; `multiLvlStrRef` read as its `f`, warning), `spPr` (`noFill`, `solidFill`, gradients/patterns as their first color, `a:ln` width/fill/`prstDash`), `marker` (`symbol`, `size`, `spPr`), `dPt` (`idx`, `spPr`, `marker`), `dLbls`, the first `trendline` (`trendlineType`, `order`, `period`, `name`, `dispEq`, `dispRSqr`, `spPr`), `smooth`; series ordered by `order`. Categories shared by every series → chart categories. `dLbls`: `showVal`, `showPercent`, `showCatName`, `showSerName`, `showLegendKey`, `dLblPos`, `numFmt` (not source-linked); per-point `dLbl` dropped (warning). Axes (`catAx`/`dateAx`/`valAx`, matched through the groups' `axId`s): `scaling` (`min`, `max`, `logBase`, `orientation`), `delete`, gridlines, `title`, `numFmt` (not source-linked), `tickLblPos`, `crosses`/`crossesAt`, `majorUnit`/`minorUnit`; the secondary category axis and `serAx` are not modelled. `title` (`tx/rich` flattened to text, paragraphs joined with `\n`; `tx/strRef`; no `tx` = automatic), `autoTitleDeleted` (absent/false with one series and no title = automatic title, as Excel shows it), `legend` (`legendPos`, `overlay`), `plotVisOnly`, `dispBlanksAs`, `c:style` (or the `mc:AlternateContent` fallback / `c14:style` − 100). Silently ignored: text properties (`txPr`, run formatting), layouts, chart area / plot area fills, tick marks, axis positions and ids, `roundedCorners`, `lang`, `date1904`, `printSettings`, `extLst`, invisible high-low/drop/series lines, zero explosions. Any other element is dropped with one warning per chart listing the element names (e.g. `errBars`, `upDownBars`, `dTable`). |
| `<hyperlinks><hyperlink ref r:id location display tooltip>` | → `Hyperlink` (P8-26) per element: `ref` (cell or range); an external target from the sheet relationship (`TargetMode="External"`) → `LinkTarget::Url`, `mailto:` → `LinkTarget::Email` (`?subject=` decoded); `location` alone → `LinkTarget::Location` (`Sheet2!B4`, a defined name); both → URL with `#location`. `display` and `tooltip` kept. A link without target or with a malformed `ref` is dropped (warning). |
| Sheet relationship `comments` → `xl/commentsN.xml` | Notes (P8-26): `<authors>` + `<commentList><comment ref authorId>` → `Note { row, col, author, text }` with the rich `<text>` (`<t>` or `<r><rPr>` runs: `b`, `i`, `strike`, `u`, `vertAlign`, `sz`, `color`, `rFont`). Legacy placeholders of threaded comments (author `tc={id}` or text starting `[Threaded comment]`) are skipped when the sheet has a threaded part. |
| Sheet relationship `vmlDrawing` → `xl/drawings/vmlDrawingN.vml` | Scanned as text (older VML is not well-formed; prefixes vary): per `ObjectType="Note"` shape `x:Row`/`x:Column`, `x:Visible` → `Note::visible`, `x:Anchor` (columns/rows + px offsets) → `Note::bounds` (points from the cell's top-right corner; the anchor Excel writes for a new note reads back as `None`); without an anchor (openpyxl) the style's `width`/`height` give the size at the default position. A missing VML part is tolerated (default boxes, warning); a VML part without comments (form controls) is dropped (warning). |
| Sheet relationship `threadedComment` → `xl/threadedComments/threadedCommentN.xml` | Threaded comments: `<threadedComment ref dT personId id parentId done><text>` → `Thread` (first comment of a cell, `done="1"` → resolved) with `Reply`s (`parentId`); a second root on a cell and replies without their comment are dropped (warning); ids are made unique in the workbook. |
| Workbook relationship `person` → `xl/persons/person.xml` | `<personList><person displayName id>` → `Workbook::persons` (comment authors; initials are not in the file). |
| Worksheet extras | Tables, sheet protection, background pictures, OLE objects and form controls are dropped with one warning per kind and sheet. Selection, page setup/margins, print options and header/footer are dropped silently. |
| `xl/metadata.xml` | Ignored (every `t="array"` formula spills); consumed without warning. |
| `<pivotCaches>` → `xl/pivotCache/pivotCacheDefinitionN.xml` (+ `pivotCacheRecordsN.xml`), sheet relationship `pivotTable` → `xl/pivotTables/pivotTableN.xml` | Pivot tables (P8-30, details in `docs/pivot.md`): `cacheSource/worksheetSource` (`ref` + `sheet`, or `name`) → `PivotSource`; `cacheField name numFmtId` with `sharedItems` (`s`, `n`, `b`, `e`, `m`, `d` → date serial) and the records (`x` indices or values) → `PivotCache` (`refreshOnLoad` kept; such a cache is refreshed after loading). `pivotTableDefinition`: `name`, `cacheId`, `location ref rowPageCount` (the anchor is above the page fields), `pivotFields` (`axis`, `items` order → sort, `h` → hidden, `sd="0"` → collapsed, `compact`/`outline` → layout, `defaultSubtotal`/`…Subtotal` → subtotals, `showAll`, `multipleItemSelectionAllowed`, `x14:pivotField fillDownLabels`), `rowFields`/`colFields` (`-2` = values, its position), `pageFields` (`item`), `dataFields` (`name`, `fld`, `subtotal`, `showDataAs`, `baseField`, `baseItem`, `numFmtId`, `x14:dataField pivotShowAs`), `dataOnRows`, `rowGrandTotals`, `colGrandTotals`, `missingCaption`, `showError`/`errorCaption`, `showHeaders`, `indent`, `pivotTableStyleInfo`. The stored cells stay; `rowItems`/`colItems`, `formats`, `conditionalFormats` and `chartFormats` are ignored. Calculated fields or items, grouped fields, label/value filters, OLAP and non-worksheet sources: the definition is kept as raw XML and written back (read-only table; one warning). |
| Other parts | Every part not listed above (images, calc chain, custom XML, VBA, …) is dropped (one warning per part). `docProps/core.xml` and `docProps/app.xml` are ignored. |

### Write

All parts are regenerated (only the theme comes from `XlsxContext` when given); output is
byte-for-byte deterministic for the same `Workbook` and context.

| Part | Content |
|---|---|
| `[Content_Types].xml`, `_rels/.rels`, `xl/_rels/workbook.xml.rels` | Via `fmt_ooxml::Package`; sheets `rId1..n`, then styles, theme, sharedStrings, metadata. |
| `xl/metadata.xml` | Only when a dynamic array formula is written: one `XLDAPR` `metadataType`, one `futureMetadata` block with `xda:dynamicArrayProperties fDynamic="1" fCollapsed="0"` and one `cellMetadata` record (`<rc t="1" v="0"/>`), which `cm="1"` on the cells points at – the structure Excel writes. Relationship type `.../relationships/sheetMetadata`, content type `application/vnd.openxmlformats-officedocument.spreadsheetml.sheetMetadata+xml`. |
| `xl/drawings/drawingN.xml` | One per sheet with charts (numbered across the workbook), related from the sheet as `rId1` (`<drawing r:id="rId1"/>` after `<pageMargins>`). Per chart (back to front) the anchor (`xdr:twoCellAnchor` without `editAs`, `xdr:oneCellAnchor`, `xdr:absoluteAnchor`) with a `xdr:graphicFrame macro=""` (`cNvPr id` = position + 2, `name`; empty `xdr:xfrm`; `a:graphicData uri=".../chart"` with `c:chart r:id`) and `xdr:clientData`. Content type `application/vnd.openxmlformats-officedocument.drawing+xml`, relationship `.../relationships/drawing`. |
| `xl/charts/chartN.xml` | `fmt_ooxml::chart::write_chart`: `date1904 0`, `roundedCorners 0`, `c:style`, `title` (rich text, one `a:p` per line; vertical axis titles rotated) + `autoTitleDeleted` (1 without title), `plotArea` with one chart group per (kind, axis) in series order (`varyColors`, group `dLbls` from the chart's labels, `gapWidth`/`overlap` when set (stacked bars without overlap get 100), `marker val="1"` with `symbol none` per series for lines without markers, `firstSliceAng` when set, `holeSize` (default 50), `scatterStyle` `lineMarker`/`smoothMarker` with `a:ln/a:noFill` per series for markers-only), series (`idx` = `order` = position; `tx` as `strRef` + `strCache` or `v`; `spPr`, `invertIfNegative 0` (bars), `marker`, `dPt`, `dLbls`, `trendline`, `cat`/`val` or `xVal`/`yVal`, `smooth`), axes with fixed ids (primary category + value; with secondary series a deleted secondary category axis and a secondary value axis on the opposite side) including `numFmt sourceLinked`, `majorTickMark out`, `tickLblPos`, `crosses`/`crossesAt`, `crossBetween` (`between` for bars/lines, `midCat` otherwise), `legend`, `plotVisOnly`, `dispBlanksAs`. Theme colors as `a:schemeClr` with `lumMod`/`lumOff`. An unsupported chart is written back as its kept XML. Content type `application/vnd.openxmlformats-officedocument.drawingml.chart+xml`, relationship `.../relationships/chart` (drawing → chart). |
| `xl/commentsN.xml` + `xl/drawings/vmlDrawingN.vml` | One pair per sheet with notes or threads (numbered across the workbook), related from the sheet (`vmlDrawing` before `comments`) with `<legacyDrawing r:id>` after `<drawing>`. Comments by cell: notes with their author (`<authors>` deduplicated) and rich text (one `<t>` for a single unformatted run, else `<r><rPr>` runs), and per thread on a cell without a note Excel's placeholder (`[Threaded comment] … Comment: … Reply: …`, author `tc={id}`, `xr:uid`) for older applications. VML: `o:shapelayout`/`o:idmap data=N`, the `_x0000_t202` shapetype, one `v:shape` per comment (`style` with margin/size in pt and `visibility`, `fillcolor="#ffffe1"`, shadow, `x:ClientData ObjectType="Note"` with `MoveWithCells`, `SizeWithCells`, `x:Anchor`, `AutoFill False`, `x:Row`, `x:Column`, `x:Visible` for shown notes); boxes without bounds get Excel's default anchor (15 px right, 10 px above the cell's top-right corner, 128 × 74 px). |
| `xl/threadedComments/threadedCommentN.xml` | Per sheet with threads: `<ThreadedComments>` with one `<threadedComment ref dT personId id [done="1"]><text>` per thread and one per reply (`parentId`). |
| `xl/persons/person.xml` | When the workbook has threads or persons: `<personList>` with `<person displayName id userId providerId="None">` for every document person and thread author (ids kept from the file, else derived from the name). |
| `docProps/core.xml`, `docProps/app.xml` | Minimal: empty core properties (no timestamps: core crates have no clock, and fixed fake dates would be misleading), `Application` = `Rusuite`. |

### Known lossy points

- Properties equal to the workbook default font, `Fill::None`, `HAlign::General`,
  `VAlign::Bottom`, `wrap_text: Some(false)`, `indent: Some(0)`, `Underline::None` and
  `bold/italic/strike: Some(false)` are written but read back as `None` (inherit).
- `FontFace::Theme` is written as the named font (`Calibri Light` / `Calibri`) and reads back as
  `FontFace::Named`. `RunProperties::highlight` and dotted/dashed/wavy underlines have no
  SpreadsheetML equivalent (underline written as single).
- A content cell without an own style inside a styled row/column is written with the row/column
  style and reads back with that style as its own style.
- Formula text of shared-formula dependents is the engine's canonical form.
- A row hidden by hand inside a range with active column filters reads back as hidden by the
  filter (`filtered`). `SortKey::kind` (`numbers`/`text`) has no SpreadsheetML attribute and reads
  back as `auto`. An `Eq` criterion written as a pattern of the contains family (`*x*`) reads back
  as `Contains`.
- Conditional formatting: rules sharing a range are written as separate `<conditionalFormatting>`
  elements (Excel groups them). Excel 2010 extensions (data bar gradients/negative bars, x14 icon
  sets) are lost; `stdDev` of above/below average rules and strict (`gte="0"`) icon thresholds
  are approximated. Theme colours of colour scales are interpolated with the default Office theme.
- Data validation: literal list values containing `,` cannot be represented (split on read);
  x14 data validations are written back as standard ones.
- Charts: all text formatting (fonts, sizes, colors of titles, labels and axes), layouts (manual
  positions of plot area, legend, titles), chart/plot area fills and borders, error bars, data
  tables, per-point labels, up/down bars, high-low/drop lines, explosions, secondary category axes,
  date axis units and multi-level categories are lost; gradients and patterns become solid fills.
  Gap width/overlap are kept once per chart (Excel stores them per bar group); settings that do not
  apply to the chart kind (gap width of a line chart, axes of a pie) are not written. Rich-text
  titles lose their runs. `mc:AlternateContent` styles are written as plain `c:style`. Drawing
  pictures and shapes are dropped. A chart reference to a deleted sheet keeps its text (not
  `#REF!`).
- Notes and comments: note boxes are stored relative to their cell (points) and converted to the
  VML anchor with Excel's pixel rounding (column widths `round(w·7+5)` px, row heights
  `round(pt·4/3)` px); VML shape properties other than the anchor and visibility (fill, shadow,
  text box insets, `x:AutoFill`, `x:SizeWithCells`) are regenerated. Person `userId`/`providerId`
  are not kept (written as the display name / `None`); `@mentions` and the `extLst` of
  threaded comments are dropped. A cell with both a note and a thread (Excel allows only one)
  writes the note as its legacy comment.
- Hyperlinks: the `r:id` relationship ids are regenerated; an external target with a
  `location` reads back as one URL with `#location`.
- Defined names: the definition text is the engine's canonical form (`'Sales'!$A$1` reads back
  as `Sales!$A$1`; a deleted reference as `#REF!`, Excel writes `Sheet1!#REF!`); the other
  `<definedName>` attributes (`customMenu`, `description`, `function`, `vbProcedure`,
  `xlm`, `publishToServer`, `workbookParameter`) are not kept; external-workbook names are
  dropped. Locale-dependent number format ids (5–8, 41–44) are written with Excel's en-US codes.

## docx (`fmt-docx`)

`fmt_docx::read(&[u8]) -> Document` and `fmt_docx::write(&Document) -> Vec<u8>` (plus
`read_with_warnings`, `read_with_context` / `write_with_context`, and native-only `read_path` /
`write_path`), mapping to `model_text::Document` (ADR 0006). The crate compiles for
`wasm32-unknown-unknown`. Transitional WordprocessingML; parts are found by relationship type
(last path segment, so strict relationship types resolve too). Unsupported content never fails
a read: it is dropped with a warning (repeats are merged into one line with a count).

### Known lossy points

- Highlight colors other than Word's 16 are written as the nearest named color (squared RGB
  distance): `black 000000, blue 0000FF, cyan 00FFFF, green 00FF00, magenta FF00FF, red FF0000,
  yellow FFFF00, white FFFFFF, darkBlue 000080, darkCyan 008080, darkGreen 008000, darkMagenta
  800080, darkRed 800000, darkYellow 808000, darkGray 808080, lightGray C0C0C0`. Run shading
  (`w:shd`) is never written.
- Complex-script twins (`bCs`, `iCs`, `szCs`) are written equal to `b`/`i`/`sz`; east-asian and
  complex-script fonts (`eastAsia`, `cs`) are not kept.
- `firstLine` and `hanging` are mutually exclusive: if both are set, only `hanging` is written.
- Line spacing `Multiple(m)` is stored in 240ths of a line (`round(m × 240)`).
- Run formatting of a break or image is not modelled (written without `w:rPr`).
- Paragraph direction (`w:bidi`, `w:rtl`) is not modelled; RTL paragraphs keep their visual
  alignment but lose their direction.
- Legacy horizontal merges (`hMerge`) stay separate cells. A table style's text formatting
  (`pPr`/`rPr`, also conditional) is kept but not layered into `resolve_paragraph_props`/
  `resolve_run_props` (see `Document::table_text_props`); row-level (`trPr`) style formatting is
  dropped.
- Floating images: `relativeHeight` (z-order), `locked`, `layoutInCell`, the wrap polygon and margin
  references other than margin/page/column/character and margin/page/paragraph/line are not kept;
  `wrapThrough` becomes `wrapTight`.
- A standalone list (`abstract_id: None`, e.g. created by `ApplyList`) is written on an abstract
  definition of its own and reads back as a list using it (same levels and labels).
- Fields other than `PAGE`, `NUMPAGES`, `DATE`, `TIME`, `FILENAME`, `AUTHOR`, `TITLE`, `REF`,
  `PAGEREF`, `NOTEREF`, `SEQ` (and `TOC`) become plain text; modelled fields are written as
  `w:fldSimple` (complex fields are not kept as such); other switches (`\* MERGEFORMAT`, `REF \p`,
  `SEQ \c`) are not kept.
- A hyperlink is an attribute of text runs: links on fields or pictures, and the `w:hyperlink`
  attributes `w:tgtFrame`, `w:docLocation` and `w:history` are not kept; a link with both
  `r:id` and `w:anchor` keeps the relationship target. Bookmarks on table rows/columns
  (`w:colFirst`/`w:colLast`) become plain text bookmarks.
- A table of contents keeps only its levels, title and entries (rebuilt from the headings on read);
  other `TOC` switches, the entries' own formatting and stale cached entries are not kept.
- Header/footer parts shared by several sections are read into each section and written once per
  section. Document-level `w:evenAndOddHeaders` is only written for a document without a settings
  part from the file (the file's settings are kept verbatim).
- Section foot/endnote properties (numbering format, position) are not modelled.

## pptx (`fmt-pptx`)

`fmt_pptx::read(&[u8]) -> Presentation` and `fmt_pptx::write(&Presentation) -> Vec<u8>` (plus
`read_with_warnings`, `read_with_context` / `write_with_context` with `PptxContext`, and
native-only `read_path` / `write_path`), mapping to `model_show::Presentation` (ADR 0008). The
crate compiles for `wasm32-unknown-unknown`. Transitional PresentationML + DrawingML; parts are
found by relationship type (last path segment). Unsupported content never fails a read: it is
dropped with a warning (repeats merged into one line with a count). The XML DOM/writer and the
theme parser are copies of `fmt-docx`'s (format crates do not depend on each other).

### Write

All parts are regenerated (only the theme may come verbatim from `PptxContext`); output is
byte-for-byte deterministic, and read → write → read gives the same presentation (ids aside) for
every reference file, for the built deck (`examples/build_deck.rs`, also `tests/built.rs`), for
the transitions-and-animations deck (`examples/anim_deck.rs`, also `tests/anim.rs`), for the
design deck (theme, master/layout backgrounds, a custom layout, every standard layout, footers,
sections, adjusted pictures: `examples/design_deck.rs`, also `tests/design.rs` with snapshots of the
master, the custom layout, `presentation.xml`, a footer slide and the picture slide) and for the
shapes deck (every preset, custom geometry, glued connectors, tables: `examples/shapes_deck.rs`, also
`tests/shapes.rs` with snapshots of its flowchart and table slides).

### Known lossy points

- Only the first master is kept; layouts of other masters are adopted only when a slide uses them.
  Layout list styles keep level 1 only (deeper levels come from the master's text styles); the
  master's and layouts' placeholder prompt texts are regenerated. A non-standard `p:clrMap` is
  kept on the master, but `tx1`/`bg1`/`tx2`/`bg2` colors in slides are always read and written
  as `dk1`/`lt1`/`dk2`/`lt2`. Header placeholders (`hdr`, notes only) are not modelled. A slide
  whose placeholders do not fit its layout (LibreOffice) is moved to an inferred standard layout;
  a PowerPoint slide whose placeholders were all deleted is moved to Blank unless its layout has
  none.
- Footer dates written as fields carry no current text (core crates have no clock): PowerPoint
  fills them in, other readers may show nothing until the UI does.
- Shapes that took their look from `p:style` get it resolved into explicit fill/outline/run color;
  effects (shadows, glow) are lost. We never write `p:style`, so text in auto shapes uses the
  master's text color (dark) unless runs set a color – PowerPoint's default white-on-accent comes
  back only when the file stated it.
- Bullet font, color and size (`buFont`, `buClr`, `buSzPct`) and paragraph indents (`marL`,
  `indent`) are not modelled; bulleted paragraphs are written with fixed indents.
- `a:br` is modelled as `"\n"` inside a run (no separate break inline); a vertical tab (U+000B) is
  written as `a:br` and reads back as `"\n"`.
- Picture effects other than those listed (artistic effects, colour change, tint, glow, soft
  edges, reflection, 3-D), the adjust values of picture shapes and non-sepia duotones' theme
  colors (resolved to RGB) are lost; PowerPoint 2010 brightness/contrast is written back as
  `a:lum`. Theme effect styles keep only an outer shadow (the original theme part is written back
  while the model's theme still equals it).
- Compound lines, shape transparency, gradients/patterns on shapes (first color kept) and preset
  geometries outside the supported library (read as rectangles) are lost. Custom geometry keeps its
  paths but not its guides, handles, connection sites or text rectangle (guides are evaluated once,
  at the shape's size when read).
- Preset geometry (outlines, adjust values and their handles, connection sites, text rectangles)
  comes from ECMA-376's `presetShapeDefinitions.xml` for every supported preset
  (`crates/model-show/src/presets/`); presets outside the library still read as rectangles.
- Connection sites are PowerPoint's (`a:cxnLst`) for every preset, plus the box centre as an
  extra last site; a site `idx` past the list means the centre when rerouting. Rerouting (only when
  the UI moves glued shapes) routes elbows glued at both ends with up to four turns around the two
  shapes' boxes (0.25" away, through the middle of the gap between them; fewest turns, then the
  shortest), others as before (one turn for sites at right angles, two otherwise). Routes that a
  box without width or height cannot hold fall back to that rule.
- Custom placeholder prompts are plain text (formatting of the prompt is not kept).
- Tables: PowerPoint's 74 built-in styles are generated from their family rules (close to, not
  byte-identical with, PowerPoint's definitions; alpha bands are written as tints) and written
  to `tableStyles.xml` for the styles used; other files' styles are interpreted from their
  parts (corner cells and diagonal borders dropped). Cell text direction, diagonal borders, 3-D cells, table
  backgrounds and inline table styles are dropped; row heights are minimums (text may grow rows in
  PowerPoint).
- Font faces map to `a:latin` only; theme east-asian/complex-script slots are written as
  `+mj-lt`/`+mn-lt`.
- Rotations are stored in 1/60000°; a model angle with more precision is rounded on write.
- Transitions: only fade, push, wipe, cover, split, cut and zoom (plus "none" with advance
  settings); PowerPoint 2010+ effects (`p14:*`, `p15:prstTrans`) fall back to the file's
  `mc:Fallback` effect or are dropped; fade through black, sounds and `p:extLst` are lost.
- Animations: only the presets above, whole-shape; Spin is always one clockwise turn and
  Grow/Shrink always 150 %; repeat, rewind, smoothing, sounds, "dim after", text-by-paragraph
  builds, motion paths, triggers (interactive sequences) and media/OLE actions are dropped.
- Charts: everything `fmt_ooxml::chart` drops (see xlsx), chart area fills and borders (written as
  none), chart rotation; multi-level categories keep their first level only via the cache; an OLE
  (`.bin`) chart workbook is dropped (a new `.xlsx` is written). Our generated workbook holds only
  the table (no formatting); a file's workbook is kept only until the data is edited.
- Hyperlinks: mouse-over actions, "run program", macros, sounds, links to other files and custom
  shows are dropped; links on master/layout shapes to slides are kept only when resolvable.
- Media: trimming, fades, bookmarks, the "When Clicked On" trigger sequence (implied by no
  `mediacall` effect), linked (not embedded) media (kept as the poster picture), video effects
  and volume steps other than the stored `vol`; a `mediacall` effect in a group with animations is
  written first in that group.
- Group children with non-uniform child scaling (`chExt` aspect ≠ `ext` aspect) are scaled
  per axis; rotated children of such groups are approximated.
