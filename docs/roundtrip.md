# Roundtrip harness

`scripts/roundtrip.sh [--identity] [--keep] [--verbose] [DIR_OR_FILE...]` (default `testdata`).

## What it does
For every `.docx/.xlsx/.pptx` below the given paths (ignoring `out/` directories):

1. Rewrites it with `$RUSUITE_REWRITE <in> <out>` (default
   `cargo run -q -p fmt-ooxml --example rewrite --`) into `<dir>/out/<name>`.
   `--identity` uses `cp` instead, to test the harness itself.
2. Converts the rewritten file to PDF with headless LibreOffice (private profile per run,
   `timeout 120`). Fails if soffice exits non-zero or writes a missing/0-byte PDF. Lines
   containing `Error` or `Warning` on soffice's output are counted as `lo_warnings`.
3. Unzips original and rewritten file and compares them: missing/added parts, and for common
   parts byte equality. With `--verbose`, differing XML/`.rels` parts are shown as a unified diff
   after `xmllint --format`.

Output, one line per file, followed by indented notes (missing/added/differing parts):

    PASS|FAIL  <path>  parts=<n> identical=<n> differing=<n> lo_warnings=<n>

`parts` is the number of entries in the original. A final summary is printed; the exit code is 1
if any file failed. `--keep` preserves the temp dirs (printed on exit).

## Interpreting results
- FAIL: rewriter error, no output, or LibreOffice could not open/convert the result.
- `differing > 0` is not a failure; it is information. A lossless rewriter should keep it at 0 for
  parts it does not understand, and differences in understood parts should be explainable
  (use `--verbose`).
- `lo_warnings > 0` deserves a look at the kept `lo.err`/`lo.out` files (`--keep`).

## Limitations
- Headless LibreOffice does not show Word/Excel/PowerPoint-style "repair" dialogs. A failed or
  empty conversion is only a proxy for "Office would complain".
- LibreOffice is lenient; passing here does not prove MS Office opens the file. Real Office
  validation is a manual step.
- The PDF is only checked for existence and size, not rendered content.
- Provisional reference files are generated by LibreOffice itself (see `testdata/README.md`).

## Requirements
`soffice`, `unzip`, `xmllint` (Debian: `libxml2-utils`). Generation additionally needs
ImageMagick `convert`; linting needs `shellcheck`.
