# docx reference suite (`testdata/docx/provisional-NN-*.docx`) - PROVISIONAL

Fifty-seven small documents (all < 60 KB) covering the Rusuite Write feature subset, one topic per file: combinations in 47–50, document structure (multilevel numbering, sections, fields, notes, table of contents) in 51–54, merged cells, floating images and paragraph borders/shading/tab stops in 55–57. They are generated by headless LibreOffice 25.2 and are **PROVISIONAL**: they only prove that LibreOffice can read them. Replace them with Word-authored files (same topic list) when the owner provides them; keep `manifest.json` accurate.

The two older files `provisional-basic.docx` and `provisional-image.docx` (from `scripts/gen-testdata.sh`) stay and are not in the manifest.

## Regenerating

```
scripts/gen-docx-suite.sh            # python generator -> .fodt -> soffice -> docx + manifest.json
scripts/gen-docx-suite.sh --verify   # existing files: valid zip, < 60 KB, converts to non-empty PDF, manifest checks
```

Source: `scripts/testdata-src/docx/gen.py` (stdlib only; helper functions plus one function per topic). Images are three generated 48x48 PNGs (gradient, checkerboard, plasma). The script rewrites all 57 files and the manifest; output is not byte-reproducible across runs (file 52 also caches the generation date in its `DATE` field). Files 51–54 were added later by converting only their `.fodt` (`gen.py emit`, then `soffice --convert-to "docx:MS Word 2007 XML"` on `provisional-5[1-4]-*.fodt`); the manifest entries of 1–50 were unchanged. Files 55–57 were added the same way (`provisional-5[5-7]-*.fodt`, LibreOffice 25.2), their manifest entries appended to the existing ones.

## manifest.json

Array of `{ "file", "topic", "features": [...], "paragraphs": N }`.
`paragraphs` is the number of `<w:p>` the generator emitted into the body (including paragraphs inside table cells, list items, empty paragraphs, image-only paragraphs and the title and entries of a table of contents; not those of footnotes, endnotes, headers and footers). A reader should report at least that many (our suite counts a table of contents as its entries plus title).

## Feature vocabulary

| Feature | Meaning |
|---------|---------|
| `title` | paragraph with style Title |
| `heading:N` | paragraph with style Heading N (1-6) |
| `style:normal` | Normal paragraphs with direct overrides |
| `run:bold` `run:italic` `run:underline` `run:strike` | character formatting |
| `run:superscript` `run:subscript` | vertical position |
| `run:font=NAME` | font family |
| `run:size=PT` | font size in points |
| `run:color=RRGGBB` | text color |
| `run:highlight=NAME` | yellow, green, cyan, magenta. LibreOffice writes this as `w:shd w:fill`, not `w:highlight`; a reader should accept both |
| `para:align=left\|center\|right\|justify` | alignment |
| `para:indent-left=Ncm` `para:indent-right=Ncm` `para:indent-first=Ncm` `para:indent-hanging=Ncm` | indentation |
| `para:space-before=Npt` `para:space-after=Npt` | spacing |
| `para:line-spacing=single\|1.5\|double\|exact\|N%` | line spacing (exact = 18 pt) |
| `para:empty` | empty paragraphs present |
| `list:bullet:levels=N` | bulleted list, deepest level N |
| `list:number:levels=N:format=decimal\|lower-alpha\|lower-roman` | numbered list |
| `list:restart` | second list restarts numbering at 1 |
| `table:rows=R:cols=C[:header]` | table size, `header` = repeated header row |
| `table:col-widths=A,B,..cm` | explicit column widths |
| `table:border=solid\|double\|dotted\|dashed`, `table:border-color` | cell border styles |
| `table:contains-list` `table:contains-image` `table:multi-paragraph-cells` | cell content |
| `image:count=N` | inline images (`w:drawing`) |
| `image:alt` | images carry alt text (`descr`) |
| `page:a4` `page:letter` | page size |
| `page:landscape` | landscape orientation |
| `page:margins=T,R,B,Lcm` | non-default margins (default 2.54 cm) |
| `break:page` `break:line` `tab` | page break, `<w:br/>`, `<w:tab/>` |
| `text:unicode` `text:rtl` | unicode samples, right-to-left paragraph (Hebrew) |
| `long:200-paragraphs` | the long document |
| `list:label=X` | a numbered paragraph's computed label is `X` (Word's counting, e.g. `1.2.1.`) |
| `section:count=N` | the document has N sections |
| `section:landscape` | some section is landscape |
| `header:default\|first\|even`, `footer:default\|first\|even` | some section has that header/footer |
| `page-number:start=N` | some section restarts page numbering at N |
| `field:page\|numpages\|date\|time\|filename\|author` | a field of that kind (body, notes, headers, footers) |
| `note:footnote=N`, `note:endnote=N` | number of footnotes / endnotes |
| `toc:levels=A-B`, `toc:entries=N` | a table of contents over outline levels A–B with N entries |
| `table:merged=horizontal\|vertical` | some cell spans several grid columns (`w:gridSpan`) / rows (`w:vMerge`) |
| `image:float=square\|tight\|top-bottom\|behind\|in-front` | a floating image (`wp:anchor`) with that wrapping (`wrapSquare`, `wrapTight`/`wrapThrough`, `wrapTopAndBottom`, `wrapNone` + `behindDoc`) |
| `image:float-align=left\|center\|right` | a floating image aligned horizontally (`wp:align`) |
| `para:border` | a paragraph with a visible border (`w:pBdr`) |
| `para:shading` | a shaded paragraph (`w:pPr/w:shd`) |
| `para:tab=left\|center\|right\|decimal\|bar`, `para:tab-leader=dot\|hyphen\|underscore` | custom tab stops (`w:tabs`) and their leaders |
