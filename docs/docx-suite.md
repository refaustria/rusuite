# docx reference suite (`testdata/docx/provisional-NN-*.docx`) - PROVISIONAL

Fifty small documents (all < 60 KB) covering the Rusuite Write feature subset, one topic per file, combinations in the last ten. They are generated by headless LibreOffice 25.2 and are **PROVISIONAL**: they only prove that LibreOffice can read them. Replace them with Word-authored files (same topic list) when the owner provides them; keep `manifest.json` accurate.

The two older files `provisional-basic.docx` and `provisional-image.docx` (from `scripts/gen-testdata.sh`) stay and are not in the manifest.

## Regenerating

```
scripts/gen-docx-suite.sh            # python generator -> .fodt -> soffice -> docx + manifest.json
scripts/gen-docx-suite.sh --verify   # existing files: valid zip, < 60 KB, converts to non-empty PDF, manifest checks
```

Source: `scripts/testdata-src/docx/gen.py` (stdlib only; helper functions plus one function per topic). Images are three generated 48x48 PNGs (gradient, checkerboard, plasma). The script rewrites all 50 files and the manifest; output is not byte-reproducible across runs.

## manifest.json

Array of `{ "file", "topic", "features": [...], "paragraphs": N }`.
`paragraphs` is the number of `<w:p>` the generator emitted (including paragraphs inside table cells, list items, empty paragraphs and image-only paragraphs). A reader should report at least that many.

## Feature vocabulary

| Feature | Meaning |
|---------|---------|
| `title` | paragraph with style Title |
| `heading:N` | paragraph with style Heading N (1-6) |
| `style:normal` | Normal paragraphs with direct overrides |
| `run:bold` `run:italic` `run:underline` `run:strike` | character formatting |
| `run:superscript` `run:subscript` | vertical position |
| `run:font=NAME` | font family |
| `run:size=PT` | font size in points |
| `run:color=RRGGBB` | text color |
| `run:highlight=NAME` | yellow, green, cyan, magenta. LibreOffice writes this as `w:shd w:fill`, not `w:highlight`; a reader should accept both |
| `para:align=left\|center\|right\|justify` | alignment |
| `para:indent-left=Ncm` `para:indent-right=Ncm` `para:indent-first=Ncm` `para:indent-hanging=Ncm` | indentation |
| `para:space-before=Npt` `para:space-after=Npt` | spacing |
| `para:line-spacing=single\|1.5\|double\|exact\|N%` | line spacing (exact = 18 pt) |
| `para:empty` | empty paragraphs present |
| `list:bullet:levels=N` | bulleted list, deepest level N |
| `list:number:levels=N:format=decimal\|lower-alpha\|lower-roman` | numbered list |
| `list:restart` | second list restarts numbering at 1 |
| `table:rows=R:cols=C[:header]` | table size, `header` = repeated header row |
| `table:col-widths=A,B,..cm` | explicit column widths |
| `table:border=solid\|double\|dotted\|dashed`, `table:border-color` | cell border styles |
| `table:contains-list` `table:contains-image` `table:multi-paragraph-cells` | cell content |
| `image:count=N` | inline images (`w:drawing`) |
| `image:alt` | images carry alt text (`descr`) |
| `page:a4` `page:letter` | page size |
| `page:landscape` | landscape orientation |
| `page:margins=T,R,B,Lcm` | non-default margins (default 2.54 cm) |
| `break:page` `break:line` `tab` | page break, `<w:br/>`, `<w:tab/>` |
| `text:unicode` `text:rtl` | unicode samples, right-to-left paragraph (Hebrew) |
| `long:200-paragraphs` | the long document |
