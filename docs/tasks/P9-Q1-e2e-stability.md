## The three tests
1. **`packages/e2e/tests/write-qa.spec.ts:228` W-23/W-25** – after the Paragraph dialog's OK, `Control+d` sometimes does not open the Font dialog (`Size (pt)` not found; fails even with the CI retry, passes alone most of the time). Hypothesis: focus is not back in the editor when the dialog unmounts, so the shortcut layer ignores the key (or Tiptap has not re-focused). Fix in the app: a dialog closed by OK/Cancel/Esc must return focus to the element that opened it (or the editor) **before** the close resolves; the shortcut map must see the key. Verify with a unit test in ui-shared's Dialog and the Write shortcut test. Then make the e2e wait for `editor` focus (`toBeFocused`) before pressing the key.
2. **`packages/e2e/tests/calc.spec.ts:621` data validation Stop alert** – `validation-alert` not visible after `Enter` on "42" in a `whole < 10` cell (fails twice in a row on the 2-core runner). Hypotheses: the Data Validation dialog's OK has not applied the rule yet when the grid is clicked (the test clicks the cell immediately after `toHaveCount(0)`), or the typed "42" started before the editor was mounted. Fix in the app if the rule application is asynchronous without a visible state (expose `data-validated`/busy state or make the dialog close only after the patch arrived); make the test wait for the rule (e.g. the Data Validation indicator or a `grid.waitIdle()` helper that resolves when no dispatch is pending – add such a helper to `support/` if missing and use it in the other validation tests).
3. **`packages/e2e/tests/write-w4.spec.ts:113` two shapes drawn, grouped, moved and resized** – a `locator.click` times out at 45 s in about 1 of 3 runs even alone against the live site. Reproduce with `--repeat-each 10` locally, read the trace, and find what blocks the click (an overlay from the drawing tool still armed? pointer capture not released after the first drag? a re-render replacing the element under the cursor?). Fix the app race, then make the test wait for the first shape to be selected/the tool disarmed before drawing the second.
