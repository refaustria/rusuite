# Task P8-31 – Write: true pagination in print layout (line-level page breaks, footnotes at page bottom, tables and columns across pages, flow options) shared by editor, print and PDF

Branch `p8/write-pagination-v2`, worktree `/home/bojan/rusuite-wt/p8-write-pagination-v2`. Scope: `apps/write/src/**` (esp. `features/pagination.ts`, `paragraphBox.ts`, print code, editor page frame; + EN/DE catalogs if needed), `apps/write/core/src/**` only if a request is genuinely needed (say so), `crates/model-text` only for `TableRow.repeat_header` (`w:tblHeader`) if missing, `packages/e2e/tests/write.spec.ts`, `docs/ui.md`, new `docs/write-layout.md` (the pagination algorithm). Up to 4 commits. Design judgement expected: read `features/pagination.ts` and the print code first and write a short design note (in `docs/write-layout.md`) before coding. Match Word's behaviour, not pixel-exactness.
1. **Measurement-based pagination**: replace block-granular breaking with line-granular breaking: measure each paragraph's line boxes in the live editor DOM (`Range.getClientRects()` per text node, merged into line rects; cache per block + width + font signature; invalidate on patches/resize/zoom), and compute page breaks at line boundaries. Rules: widow/orphan control (2 lines) when `widow_control`, `keep_lines` (move the whole paragraph), `keep_next` (keep with the next block's first lines), `page_break_before`, explicit page/section breaks, section page setup (size/margins/orientation/columns per section, first/even/odd headers – already there), headers/footers height reserved from the measured header/footer blocks (not a constant), tables: split between rows (never inside a row unless the row is taller than a page → allow splitting the row's cell content at line boundaries only when `cant_split` is false), repeated header rows (`repeat_header`) redrawn at each page top; floating images: page-relative/margin-relative positions resolved against the real page box (fixing the P8-17 limitation), and their wrap exclusion zones taken into account by the line measurement (approximation: shape-outside on the page frame or shift the anchor paragraph's line boxes); multi-column sections: fill column 1 then column 2 within the page, balance on the last page of the section, column breaks honoured.
2. **Footnotes/endnotes**: footnotes placed at the bottom of the page where the reference line lands; the footnote area height reduces the body space (iterate: place lines, reserve notes, re-break if needed, max 3 iterations; long footnotes continue on the next page with a continuation separator); endnotes at the document end (or section end when configured); the duplicated footnote display in print layout (P8-10 limitation: read-only at page bottom + editable in the notes area) becomes one editable area per page in print layout, draft view keeps the notes area.
3. **One layout for all surfaces**: the editor's print layout, the Print backstage preview and the PDF export consume the same `PageLayout { pages: [{ section, columns: [{ fragments: [{ block, fromLine, toLine, rect }] }], header, footer, footnotes }] }`; page numbers, NUMPAGES, PAGEREF, TOC page numbers and "Page X of Y" in the status bar come from it; zoom and window resizes relayout with a 60 ms debounce; large documents (≥ 200 pages) stay responsive by paginating incrementally from the first dirty block (measure only visible + dirty pages; virtualize page frames out of view).
4. **Editor behaviour across page breaks**: the caret moves naturally across the gap (line up/down, PageUp/PageDown by page), selection highlights span the break, drag-select across pages, click in the gap selects the nearest line; the page gap shows the page number on hover (Word-style "Page 3"); double-click a gap hides/shows white space between pages (Word's "Hide White Space").
5. **Tests**: ≥ 40 unit (line-rect merging, break rules per flow option, table row splitting with repeat header, footnote reservation iteration, column balancing, PageLayout → page-number fields, incremental re-pagination invalidation) using a measurement stub; 6 e2e (a 3-page lorem document breaks inside paragraphs (a paragraph straddles pages: count lines on page 1 vs 2 via bounding boxes); widow control moves the last line; a long table repeats its header row on page 2 (saved `w:tblHeader`); a footnote appears at the bottom of its page in print layout AND in the print preview; two-column section flows across pages; PDF export page count equals the editor page count).
Acceptance: full definition of done (`pnpm test`, tsc, i18n:check, builds, e2e on a private port with own serve.mjs stopped by PID only), screenshots; perf note for a 200-page document in `docs/perf.md`; no deploy.
