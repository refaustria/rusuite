## Deliverables
- `state/store.ts`: presentation state from `getPresentation`/patches (`ShowPatch` applies whole slides; `id_map` rewrites temp ids), current slide, selection (shape ids), revision discard, toasts. `api.ts`: typed wrapper per request kind.
- `canvas/Stage.tsx` (react-konva): renders the current slide at a scale fitting the viewport; EMU → px via `slideSize`; each `Shape` → Konva node keyed by `NodeId` (Rect/Ellipse/Line/Image/Group; text rendered with `Konva.Text` inside the shape honouring anchor, alignment, bullets (prefix char/number rendering is fine), run formatting as far as Konva allows (per-run font/colour via multiple Text nodes or `Konva.Text` with rich text emulation – document the limits)); `Transformer` for selection with move/resize/rotate → `SetTransform` on drag end (one command per gesture); shift-click multi-select; marquee select; Delete key → `DeleteShapes`; arrow keys nudge (1 px / 10 px with Shift) → `SetTransform`; Ctrl+D duplicate (→ `AddShape` copies); Ctrl+G/Ctrl+Shift+G group/ungroup; z-order shortcuts (Ctrl+]/Ctrl+[ …) → `ZOrder`; alignment buttons → `Align`/`Distribute`.
- Text editing: double-click a text-bearing shape → overlay `<textarea>`/contenteditable positioned over the shape with matching font/size; on blur/Esc/Ctrl+Enter commit → `SetTextBody` with paragraphs split on newlines (preserve existing paragraph props by index; new paragraphs copy the previous ones). Toolbar (ui-shared Toolbar: font, size, bold/italic/underline/strike, colours) applies `SetRunProps` to the whole text body of selected shapes (all paragraphs, full ranges) or, while editing, to the selection (map textarea selection → paragraph/run offsets); paragraph alignment buttons → `SetParagraphProps`; bullet toggle; shape fill/line colour pickers → `SetShapeStyle`.
- Insert: Rectangle, Ellipse, Line, Text box (`AddShape` with a default transform in the slide centre), Image (file input → `InsertPicture`).
- `sidebar/SlideList.tsx`: thumbnails rendered from the model (a scaled read-only Stage per slide or an offscreen canvas `toDataURL` cached per revision), click to select, drag to reorder → `MoveSlide`, "+" menu for the three layouts → `AddSlide`, Delete/Duplicate context actions.
- `present/Presenter.tsx`: fullscreen (Fullscreen API; fallback to a full-window overlay), slide scaled to screen, keys: → / Space / PageDown next, ← / PageUp previous, Home/End, Esc exits; click advances.
- `App.tsx`: toolbar / sidebar + stage / status bar (slide i/n, revision, dirty, name); Undo/Redo (Ctrl+Z/Y) through the core; Open/Save buttons wired like Write (`openPptx`/`savePptx`/`markSaved` – the requests arrive with P4-7; if they are not on main when you start, implement the buttons against the request names above and keep them disabled with a tooltip until the dispatcher answers; say so).
- Tests (vitest, react-konva mocked where rendering is needed): store/patch application incl. id_map and slide reorder; EMU↔px geometry; transformer-end → `SetTransform` command shape; text overlay commit → `SetTextBody` paragraphs; keyboard shortcuts → commands; presenter navigation; ≥ 25 tests.
