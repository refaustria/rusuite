## Goal
A working spreadsheet view against the real backend through `Backend.dispatch`: virtualized canvas grid, selection, in-cell editing and a formula bar, column/row headers with resize, sheet tabs, undo/redo shortcuts, and live updates from `CalcPatch`. Works identically in Tauri and in the web build (no Tauri imports).

## Architecture (`apps/calc/src/`)
- `state/store.ts`: a small store (zustand is allowed as the one new runtime dep, or a hand-rolled `useSyncExternalStore` store – your call, state the reason) holding `WorkbookInfo`, the active sheet, selection (`anchor`, `focus` → normalized range), edit mode, and a **sparse cell cache per sheet**: `Map<rowIndex, Map<colIndex, CellView>>`, plus col/row dimension maps. `applyPatch(patch)` merges `CalcPatch` into the cache (a `structural` patch drops the sheet's cache and reloads the viewport). `ensureRegion(sheet, r0,c0,r1,c1)` requests `Snapshot` for viewport blocks not yet cached (block size 64×32, de-duplicated in-flight requests).
- `backend/calcApi.ts`: typed wrappers over `backend.dispatch` for each `Request` kind; every response validated against the `Response` union; errors surface as a toast (simple component).
- `grid/GridCanvas.tsx`: one `<canvas>` for cells + one for headers, device-pixel-ratio aware, draws only the visible rows/cols using cumulative offsets (binary search over prefix sums of widths/heights; defaults 64 px × 20 px scaled from Excel units: width chars × 7 + 5 px, height pt × 96/72). Text rendering honours `CellView.style` (resolved through `WorkbookInfo.styles`): font family/size/bold/italic/color, fill, borders, horizontal alignment (default by `kind`: numbers right, text left, bool/error center), wrap off (clip) for MVP. Scrolling via a scroll container with a sized spacer (virtual height = rows up to used range + 50 rows, min 200; grows as you scroll – not 1M rows of DOM). 60 fps target for scrolling a 100k-cell region (measure with `performance.now()` in a dev overlay, report numbers).
- `grid/Selection.ts`: mouse down/drag/shift-click range selection, keyboard navigation (arrows, Tab/Enter move, Ctrl+Arrow jump to data edge, Shift extends, Ctrl+A used range, Page Up/Down), Home/End.
- `grid/CellEditor.tsx`: an absolutely-positioned `<input>` overlaid on the active cell: F2 or typing starts editing (typing replaces, F2 appends), Enter commits & moves down, Tab commits & moves right, Esc cancels; commit sends `SetInput`. Delete/Backspace on a selection → `ClearRange`.
- `FormulaBar.tsx`: shows the active cell address (`A1`, `Sheet2!B3` when needed) and `input`; editable; synced with the cell editor.
- `SheetTabs.tsx`: tabs from `WorkbookInfo.sheets`, click to switch, "+" → `AddSheet`, double-click → `RenameSheet` (inline).
- Headers: click selects whole row/col (selection ranges may be whole-row/col: represent as ranges clipped to a large constant, e.g. 1048576/16384, but only request snapshots for the viewport); drag on the header boundary resizes → `SetColWidth`/`SetRowHeight` on mouse up; double-click boundary → autofit to the widest visible cell text (measure with canvas `measureText`).
- Keyboard: Ctrl+Z / Ctrl+Y (and Ctrl+Shift+Z) → `Undo`/`Redo`; Ctrl+B/I/U → `ApplyStyle` on the selection (toggle based on the active cell's style). Ctrl+C/Ctrl+V: internal clipboard of the selected `input`s as TSV; paste writes `SetInput` per cell (formula reference adjustment is a later task – paste formulas verbatim for now; note it).
- Mount `Toolbar` from `@rusuite/ui-shared` above the grid IF it exists on main when you start (check `packages/ui-shared/src/toolbar/`); otherwise leave a `<div id="toolbar-slot">` and say so.
- `App.tsx`: layout = toolbar slot / formula bar / grid / sheet tabs / status bar (`revision`, dirty flag, cycle warning text from the last patch). On start: `NewDocument` then `Info` then the first viewport snapshot.
