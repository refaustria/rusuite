## Goal
`fmt_xlsx::read(&[u8]) -> Result<Workbook>` and `fmt_xlsx::write(&Workbook) -> Result<Vec<u8>>` for the README Calc subset: multiple sheets, cell values (number/text/bool/error/date-as-serial), formulas, cell styles (font, fill, borders, alignment, number format), column widths/hidden, row heights/hidden, sheet default format. Files we write must open in LibreOffice headless (harness) and must be valid for Excel (owner verifies).

## Reading (parts via `fmt_ooxml::Package`)
- `xl/workbook.xml`: `<sheets>` order, names, `r:id` → worksheet part via rels; `<definedNames>` ignored (ROADMAP); `workbookPr date1904` → if set, return `Error::Unsupported("date1904")`.
- `xl/sharedStrings.xml`: `<si><t>` and rich text `<si><r><t>` concatenated (formatting of runs dropped); respect `xml:space="preserve"`.
- `xl/styles.xml`: `<numFmts>` (id → code), `<fonts>` (name, sz, b, i, u single/double, strike, color rgb/theme+tint/indexed via the legacy indexed palette table), `<fills>` (patternFill solid fgColor; `none`/`gray125` → None), `<borders>` (left/right/top/bottom style + color), `<cellXfs>` (fontId, fillId, borderId, numFmtId, applyX flags honoured as Excel does: if `applyNumberFormat="0"` is explicitly present ignore numFmtId? – NO: Excel actually uses the ids regardless; take the ids, ignore apply flags; `<alignment horizontal vertical wrapText indent>`). Map to `model_sheet::CellStyle` and intern; keep a `Vec<StyleId>` indexed by xf index. Number format: builtin id → code via `model_sheet::numfmt::builtin_code`; custom → the code string; id 0 → None.
- `xl/theme/theme1.xml`: parse `<a:clrScheme>` into `core_model::ColorScheme` to resolve `theme="N"` colors into `Color::Theme { slot, tint }` (do not resolve to RGB – keep theme colors as theme colors). Keep the raw theme part bytes to write back verbatim.
- Worksheets `xl/worksheets/sheetN.xml`: `<sheetFormatPr defaultColWidth defaultRowHeight>`, `<cols><col min max width hidden style customWidth>`, `<sheetData><row r ht hidden s customFormat><c r s t><f/><v/><is/>`. Cell types: `t="s"` shared string index, `t="str"` formula string result, `t="b"`, `t="e"`, `t="inlineStr"` (`<is><t>`), `t="n"`/absent → number. A formula cell: `<f>` text → set input `"=" + text` (the engine recomputes; the cached `<v>` is ignored except for a debug comparison). Shared formulas: `<f t="shared" ref=.. si=..>TEXT</f>` on the master; dependents `<f t="shared" si=..>` without text → derive by `engine_formula::offset_relative(master_ast, drow, dcol)`. Array formulas (`t="array"`) → treat as normal formula of the top-left cell (ROADMAP). Text input that would be re-parsed as a number/bool (e.g. shared string "0123") must be stored as Text: use `Workbook::set_content(CellContent::Value(Value::Text(..)))` rather than `set_input`. Load inside `begin_batch`/`end_batch`.
- `_xlfn.` prefixes on function names (e.g. `_xlfn.CONCAT`) are stripped on read and re-added on write for the functions Excel requires it for (CONCAT, IFS, TEXTJOIN, XLOOKUP, DAYS… – keep a small table; for our 62 functions: CONCAT and DAYS).
- Unsupported parts (charts, drawings, pivot, comments, data validation, conditional formatting, merged cells, hyperlinks, defined names, freeze panes) are dropped with a `warnings: Vec<String>` list returned alongside the workbook (`read_with_warnings`). Merged cells: record in warnings (ROADMAP). Document all of this in `docs/ooxml-subset.md`.

- All XML via quick-xml writer with proper escaping; `standalone="yes"` declaration from `fmt_ooxml::xml`.
- Deterministic output (same Workbook → identical bytes).
