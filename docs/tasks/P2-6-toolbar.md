## Deliverables (`packages/ui-shared/src/`)
- `toolbar/Toolbar.tsx`: a single-row toolbar (ribbon-lite) with groups: **Clipboard-free** (no copy/paste buttons – keyboard only), **Font** (`FontPicker`: select with the 8 common families Arial, Calibri, Cambria, Courier New, Georgia, Helvetica, Times New Roman, Verdana + the current value if not in the list; `FontSizePicker`: 8–72 presets, editable), **Style toggles** (bold/italic/underline/strikethrough), **Colors** (`ColorPicker` popover for text color and fill color: theme palette 10 columns × 6 tint rows from a `theme` prop (default Office colors, tints −0.5/−0.25/0/0.4/0.6/0.8 like Excel), 10 standard colors, "Automatic/No fill", hex input), **Alignment** (left/center/right, top/middle/bottom, wrap), **Number format** (select: General, Number `0.00`, Thousands `#,##0`, Currency `#,##0.00`, Percent `0%`, Date `yyyy-mm-dd`, Text `@`), **Borders** (dropdown: none, all, outline, bottom, top, left, right – thin black).
- Props: `value: CellStyleView` (the resolved style of the active cell/selection; a partial type mirroring `CellStyle` with all fields optional), `onChange(patch: CellStylePatch)` where the patch is the `CellStyle`-shaped JSON the backend's `ApplyStyle` expects (only the changed field set; toggles compute `bold: !value.font?.bold`), `disabled`, `theme`. The toolbar is **controlled** and stateless apart from popover open state.
- `Dialog.tsx` (modal with focus trap, Esc to close) and `Dropdown.tsx`/`Popover.tsx` primitives used by the pickers; `Icon.tsx` with inline SVG icons (no icon font dependency) for the ~20 icons needed.
- `styles.css`: Tailwind 4 theme tokens (`--color-ui-*`), light and dark via `prefers-color-scheme`.
- Accessibility: every control has an `aria-label`, toggles use `aria-pressed`, pickers are keyboard operable (arrow keys in the color grid), visible focus ring.
- Tests (vitest + testing-library): toggle emits the right patch from a given value; number-format select emits `{ numberFormat: "0.00" }`; color grid emits `{ font: { color: { kind: "theme", value: { slot: "accent1", tint: 0.6 } } } }` for a tint cell and `{ kind: "rgb", value: "FF0000" }` for a standard cell; disabled state renders all controls disabled; `Dialog` traps focus and closes on Esc. A Storybook is NOT wanted; instead `src/toolbar/demo.tsx` exports a `ToolbarDemo` component with local state (used by the grid task for manual checks).
- No new runtime dependencies beyond React (no Radix/Headless UI); dev deps as needed (`@testing-library/user-event` ok).
