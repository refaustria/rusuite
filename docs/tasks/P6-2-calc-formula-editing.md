# Task P6-2 – Calc formula editing like Excel

Branch `p6/calc-formula-ux`, worktree `/home/bojan/rusuite-wt/p6-calc-formula-ux`. Scope: `apps/calc/src/grid/**`, `apps/calc/src/FormulaBar.tsx`, `apps/calc/src/state/**`, new `apps/calc/src/formula/**`; do NOT touch `App.tsx` (the ribbon task owns it; if you need a new prop, expose it via the store). Owner feedback (2026-10-15): typing `=` and clicking cells exits the cell, and an incomplete formula is deleted – "not really user friendly".

Implement Excel's editing model:
1. **Edit modes**: `enter` (started by typing: arrow keys commit and move) vs `edit` (F2 or double-click: arrows move the caret). While the text starts with `=` and the caret is at a position where a reference may be inserted (after `=`, an operator, `(` or `,`, or the caret is on an existing reference), the editor is in **point mode**: clicking a cell inserts/replaces its reference (`A1`), dragging inserts a range (`A1:B3`), clicking a sheet tab then a cell inserts `Sheet2!A1`, arrow keys move a "reference cursor" inserting references (Excel's keyboard pointing), Shift+arrows extend the range; F4 cycles `$` anchoring of the reference under the caret; typing continues the formula; Enter/Tab commit; Esc cancels.
2. **Never lose text**: committing an unparsable formula shows an inline error under the cell/formula bar ("Unexpected end of formula – fix or press Esc to discard") and keeps editing (Excel shows a dialog; we keep it inline); blur (clicking outside the grid, e.g. the toolbar) keeps the editor open rather than committing/discarding; only Enter/Tab/clicking another cell while NOT in point mode commits. Commit of a formula with a `#NAME?`-style result is fine (value error, not parse error).
3. **Reference highlighting**: while editing, each reference in the formula text gets a colour (Excel's palette: blue, red, purple, green, …) and the referenced ranges are outlined on the grid in the same colour; the formula-bar text shows the colours too (overlay of coloured spans behind the input).
4. **Function autocomplete**: after typing letters at a function position, a dropdown lists matching functions from `docs/functions.md` (ship the list as a small generated JSON in `apps/calc/src/formula/functions.json` with name + signature, produced by a script `scripts/gen-function-list.sh` from docs/functions.md); Tab/Enter accepts (`SUM(`); a signature tooltip (`SUM(number1, [number2], …)`) shows while inside the call with the current argument bold.
5. **Formula bar parity**: the formula bar and cell editor are the same edit session (typing in either updates both; point mode works from the bar too); `fx` button opens the autocomplete list.
6. Keep: Delete/Backspace on selection, Ctrl+Z, paste. Update `docs/shortcuts.md` (F2, F4, point mode).
Tests (≥ 25): point-mode detection on caret positions, reference insertion/replacement, range drag text, sheet-qualified refs, F4 cycling, reference colouring tokenizer, autocomplete filtering, incomplete-formula commit keeps editing with the error, blur does not discard, enter vs edit mode arrow handling.
