Notes beyond docs/functions.md:
- AVERAGE/MIN/MAX/PRODUCT use `Aggregate::Numbers` like SUM; AVERAGE of zero numbers → `#DIV/0!`; MIN/MAX of zero numbers → 0.
- COUNT: counts Numbers; direct scalar args that are numbers, bools, or numeric text count (Excel counts `COUNT("3")`=1, `COUNT(TRUE)`=1); in ranges only Numbers count; errors never propagate (they are simply not counted). COUNTA: counts every non-Empty value in ranges (errors included), every direct arg that is not Empty/Missing.
- ROUND family: Excel rounds half away from zero; handle negative `num_digits` (`ROUND(1234.5678,-2)`=1200); guard against floating noise by rounding `x * 10^d` after adding a tiny epsilon toward away-from-zero (`ROUND(2.675,2)`=2.68 in Excel). ROUNDUP/ROUNDDOWN are away-from/toward zero. INT is floor (toward -∞). MOD(n,d) = n - d*INT(n/d), MOD(x,0) → `#DIV/0!`. CEILING(x, sig): sig=0 → 0; x and sig with different signs → `#NUM!`; result = sig * ceil(x/sig) (away from zero for negatives with negative sig).
- SUMIF(range, criteria, [sum_range]) and COUNTIF(range, criteria) share a `criteria.rs` helper: criteria is a scalar; if Text and it starts with `<>`, `>=`, `<=`, `>`, `<`, `=` → operator + the remainder parsed as number if possible else text; otherwise equality. Equality on text is case-insensitive and supports wildcards `*` `?` with `~` escape. A numeric criterion matches Numbers only (not numeric text in the range); a text criterion matches Texts (and `=` / empty criterion matches Empty cells for COUNTIF(.., "")). Bool criteria match Bools. `sum_range` is aligned by top-left offset and may be smaller/larger (Excel extends/clips to the shape of `range`).
- SUMPRODUCT: all array/range args must have equal shape (else `#VALUE!`); non-numeric entries count as 0; errors propagate.
- POWER follows the `^` operator rules (reuse the operator code if exposed; otherwise match: `0^0`→#NUM!, negative base with fractional exponent → #NUM!). SQRT of negative → `#NUM!`. PI() takes no args.
