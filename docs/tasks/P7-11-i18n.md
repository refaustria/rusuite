## Library (`packages/ui-shared/src/i18n/`)
- `createI18n({ locales: { en, de }, fallback: 'en' })` → `t(key, params?)` with `{name}` interpolation and simple plurals (`key.one` / `key.other` chosen by `params.count`), `useT()` hook, `<I18nProvider locale>`; `formatNumber/formatDate` via `Intl` for the UI chrome (status bars, dialogs) – NOT for cell values (see below).
- Catalogs: `locales/en.json`, `locales/de.json` per package (`ui-shared`, each app, portal) with namespaced keys (`ribbon.home`, `dialog.save.title` …). A vitest test in each package asserts that `de.json` has exactly the keys of `en.json` (no missing/extra), and a script `scripts/i18n-check.mjs` greps for literal JSX text/`aria-label`/`title`/`placeholder` strings outside the catalogs (allow-list for brand names, file extensions, `fx`, shortcut combos) – run in CI (`pnpm i18n:check`).
- Locale selection: `navigator.language` (de* → de) by default; user override in the ribbon View tab ("Language / Sprache": English, Deutsch) and in the backstage; persisted (localStorage on web, app data via `Backend.storage` on desktop); changing it re-renders without reload; `<html lang>` updated; the portal offers a small EN/DE switch and honours the browser language.
- German translations: natural, concise, Office-style terminology (Datei, Start, Einfügen, Ansicht, Layout, Entwurf, Speichern unter…, Rückgängig, Wiederholen, Ausschneiden, Kopieren, Einfügen, Fett, Kursiv, Unterstrichen, Zellen formatieren…, Suchen und Ersetzen, Seitenlayout, Kopf-/Fußzeile, Folie, Layout, Anordnen, Bildschirmpräsentation, Referentenansicht, Notizen, Drucken, Seitenansicht). Keep shortcuts identical (Ctrl+…; German Office uses Strg – show "Strg" in the German help dialog and tooltips).
## Explicitly NOT in this task (decision pending with the owner, see STATUS): formula language. Function names stay English (`SUM`, not `SUMME`), the argument separator stays `,` and the decimal point `.` in formulas and cell values. Number/date DISPLAY in cells stays en-US. A follow-up task will add locale-aware input/display and `;` separators if the owner wants it.
