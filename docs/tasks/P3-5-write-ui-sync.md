## Deliverables
- `src/sync/schema.ts`: Tiptap extensions for the document: `paragraph` (attrs `id`, `align`, `indent`, `spacing`, `style`), `heading` (levels 1–6 = paragraph with style `Heading1..6`; attr `id`), `title` (style `Title`), `bulletList`/`orderedList`/`listItem` (StarterKit) with a custom `ListMapping` layer (ADR 0007 §4), `table`/`tableRow`/`tableCell` (`@tiptap/extension-table` family, pinned ≥ 2 weeks old; attrs `id`, cell `shading`, `width`), `image` (inline, attrs `mediaId`, `width`, `height`, `alt`, rendered via a blob URL from `GetMedia`), `hardBreak`, `pageBreak` (custom inline atom). Marks: `bold`, `italic`, `underline`, `strike`, `superscript`, `subscript`, `textStyle` (font family/size/color/highlight as attrs). Disable StarterKit's `history`, `blockquote`, `codeBlock`, `horizontalRule`.
- `src/sync/toPM.ts` / `fromPM.ts`: `Document` JSON → PM doc and back (`Block[]` ↔ nodes, runs ↔ text with marks, numbering ↔ nested lists with levels, tables). Property tests: for every file in `testdata/docx/manifest.json` loaded through the core (`Load` with the JSON of… – the core cannot read docx until P3-7; instead use a fixture set of `Document` JSONs generated in a vitest setup by calling the wasm core's `NewDocument` + a scripted set of `Apply` commands, OR hand-written JSON fixtures covering: headings, lists 3 levels, table, image, breaks, mixed marks) assert `fromPM(toPM(doc))` equals `doc` after normalization (ignore ids order, run merging).
- `src/sync/transactionMapper.ts`: given a PM transaction (steps + old/new docs), produce a `WriteCommand` (fine-grained: `InsertText`, `DeleteText`, `ReplaceText`, `SetRunProps`, `SplitParagraph`, `JoinWithPrevious`, `SetParagraphProps`, `ApplyList`, `IndentList`; else `ReplaceBlocks` of the top-level blocks whose range intersects the changed range). Unit tests per step type incl. typing in the middle of marked text, Enter at end/middle of a heading, Backspace joining paragraphs, toggling bold on a selection, toggling a bullet list on two paragraphs, a paste of multiple paragraphs (→ ReplaceBlocks/InsertBlocks), and a change inside a table cell (→ ReplaceBlocks of the table).
- `src/sync/SyncPlugin.ts`: PM plugin that (1) tags new nodes with temp negative ids, (2) on every transaction sends the mapped command with the current revision via `dispatch`, (3) reconciles the `WritePatch`: apply `idMap`, compare each `replaced`/`inserted` block with the local node (structural equality via `fromPM` of that node vs the block); replace on mismatch with selection mapping; (4) discards stale revisions; (5) on `err` reloads the affected blocks via `GetDocument` (whole doc for MVP) and shows a toast. Undo/redo: Ctrl+Z/Y → `Undo`/`Redo` requests, patch applied the same way.
- `src/App.tsx`: toolbar (ui-shared Toolbar for run formatting + new `ParagraphStyleSelect` (Normal/Title/Heading 1–6) + list buttons + align buttons + indent/outdent + insert table/image buttons + Find/Replace dialog using the `FindReplace` command), editor, status bar (words, revision, dirty, document name). Image insert: file input → `InsertImage` with base64, size from the image's natural size (capped to page content width).
- Keep `?fake=1` out; tests run against a fake backend implementing the request kinds, or against the real wasm core if loadable in vitest (try; report).
