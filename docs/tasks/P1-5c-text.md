Implement (13): CONCAT CONCATENATE LEFT RIGHT MID UPPER LOWER TRIM FIND SUBSTITUTE TEXT VALUE EXACT.
Notes beyond docs/functions.md:
- All positions/lengths are in Unicode scalar values (chars), not bytes. Negative length / position < 1 → `#VALUE!`; MID beyond the end → `""`. LEFT/RIGHT default length 1.
- CONCAT accepts ranges/arrays (every element in row-major order, Empty → ""); CONCATENATE accepts only scalars (a multi-cell range → implicit intersection via `ctx.scalar`). Numbers are converted with `to_text` (General format).
- TRIM removes leading/trailing ASCII spaces and collapses internal runs of spaces to one (only U+0020). UPPER/LOWER use Rust's Unicode case mapping.
- FIND(find_text, within_text, [start]) is case-sensitive, no wildcards; not found → `#VALUE!`; start < 1 or > len+1 → `#VALUE!`. SUBSTITUTE(text, old, new, [instance]) case-sensitive; instance < 1 → `#VALUE!`; empty `old` returns text unchanged. EXACT is case-sensitive equality.
- VALUE(text): uses `crate::value::parse_number_text` (same acceptance as the `+` operator) PLUS: percent, and ISO dates `yyyy-mm-dd` → date serial and `hh:mm[:ss]` → fraction of a day (write a small parser in `text/value.rs`, reuse nothing from the datetime batch – they run in parallel; duplicate the serial computation locally in a private fn if needed and mention it in the report). Bool text → `#VALUE!`. Numbers/bools passed directly: Number → itself, Bool → `#VALUE!`.
- TEXT(value, format_text): implement a `text/numfmt.rs` supporting exactly the MVP codes from `docs/functions.md` (`0`, `0.00`, `#,##0`, `#,##0.00`, `0%`, `0.0%`, `yyyy-mm-dd`, `dd.mm.yyyy`, `mm/dd/yyyy`, `@`) with a general mechanism: split on `;` (positive;negative;zero sections – negative section without explicit `-` adds none; a missing negative section prints `-` + positive format), digit placeholders `0` and `#`, thousands separator `,`, decimal `.`, percent `%` (×100), literal text in quotes `"..."`, and date tokens `yyyy yy mm dd` (month vs minute ambiguity: `mm` is month unless it directly follows `hh`/`h` or precedes `ss`), `hh mm ss`. Rounding half away from zero. Unknown/unsupported code → implement as literal passthrough of the characters you do not understand, and list what you skipped. Text input with `@` returns the text; numeric formats on text input return the text unchanged (Excel behaviour).
