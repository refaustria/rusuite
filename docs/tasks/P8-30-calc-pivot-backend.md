1. **Model**: `Workbook.pivot_caches: Vec<PivotCache { id, source: Range{sheet, rect} | Table(name) | Name(name), fields: Vec<CacheField { name, shared_items: Vec<Value> (for row/col/page fields), kind: Number|Text|Date|Mixed, contains_blank }>, records: computed on refresh (not stored in memory beyond what xlsx needs), refresh_on_load }>`, `Sheet.pivots: Vec<PivotTable { id, name, cache_id, location: Rect (incl. header rows), rows: Vec<AxisField { field, sort: Asc|Desc|Manual(order), subtotals: Automatic|None|Vec<Fn>, show_all_items, collapsed_items: Set, layout: Compact|Outline|Tabular }>, cols: Vec<AxisField>, filters (page fields): Vec<PageField { field, selected: All|Items(set) }>, values: Vec<DataField { field, name, func: Sum|Count|Average|Max|Min|Product|CountNums|StdDev|StdDevP|Var|VarP, show_as: Normal|PercentOfTotal|PercentOfRow|PercentOfColumn|PercentOfParent|DifferenceFrom{base}|RunningTotal{base}|Rank, number_format }>, options: { grand_total_rows, grand_total_cols, row_headers_bold, banded, style: String ("PivotStyleLight16" default), values_in: Rows|Columns, empty_as: String, error_as: String, repeat_labels, show_field_headers, compact_rows_indent } }>`; `PivotTable::compute(cache) -> PivotOutput { cells: Vec<(row, col, value, kind: Header|RowLabel|ColLabel|Value|Subtotal|GrandTotal|Blank, level, collapsed?)>, extent }` implementing Excel's layout rules (compact form default: row labels nested with indentation in one column; outline/tabular variants; subtotals at top (compact/outline) or bottom (tabular); grand totals; multiple value fields → "Values" axis; column fields crosstab; sorting incl. by value field omitted (manual + A–Z only); dates grouped as values (no auto-grouping yet)); the output is written into the sheet as plain cells with a `pivot_id` marker so normal rendering/printing works and cells inside a pivot are read-only for direct edits (`EditError::PivotCell`); `Workbook::refresh_pivot(id)` re-reads the source, rebuilds the cache items, recomputes and rewrites the cells (grow/shrink; refuses if it would overwrite non-empty non-pivot cells → error with the conflicting range, as Excel does).
2. **Engine**: `GETPIVOTDATA(data_field, pivot_cell, [field, item]...)` resolving against the pivot output at `pivot_cell` (any cell inside the pivot), `#REF!` when not found; auto-generation of GETPIVOTDATA formulas when pointing at a pivot cell is a UI concern (note it in docs/pivot.md).
3. **xlsx**: read/write `xl/pivotCache/pivotCacheDefinition{N}.xml` (cacheSource worksheetSource ref/sheet or name, cacheFields with sharedItems incl. `containsNumber/containsString/containsBlank/minValue/maxValue`), `pivotCacheRecords{N}.xml` (records as `<x v="i"/>` indices / `<n v/>` / `<s v/>` / `<b/>` / `<d/>` / `<m/>`), `xl/pivotTables/pivotTable{N}.xml` (location, pivotFields with items + axis + dataField flags, rowFields/colFields/pageFields/dataFields, rowItems/colItems (write them exactly so Excel does not need a refresh: `<i t="default">`, `<i r="1">`, grand `t="grand"`), pivotTableStyleInfo, `dataOnRows`, `outline`/`compact` flags, `updatedVersion="6"`), workbook `pivotCaches` list + rels + content types; on read, prefer our recomputation when `refresh_on_load` is set, otherwise keep the sheet cells as stored but attach the pivot definition; unsupported features (calculated fields/items, slicers, timelines, OLAP) → warning, definition kept as raw XML and re-emitted.
