## Items (one commit each, with regression tests; up to 5 commits)
1. **Rich in-place editor (QA S-01).** While editing a shape's text in place: bullets on/off and numbering (Home › Paragraph), indent level with Tab / Shift+Tab (levels 1–9, PowerPoint's per-level indents and bullet characters from the master), alignment, line spacing, run formatting (bold/italic/underline/strikethrough/colour/size/font, Ctrl+B/I/U, Ctrl+]/[ size steps, Ctrl+Shift+> / <) applied to the current selection and shown immediately; **Shift+Enter** inserts a line break (`a:br`), Enter a new paragraph that inherits the paragraph properties; Ctrl+A selects the shape's text; mixed formatting across paragraphs/runs is preserved (no flattening on commit). Typing merges into one undo step per editing session like today's behaviour, formatting changes are their own steps. The editor must keep the model's runs/paragraphs 1:1 (round-trip test: edit → model → render equals the editor's view).
2. **Autofit and prompt text.** New text boxes use `spAutoFit` (shape grows with the text, PowerPoint default); placeholders use `normAutofit` (shrink on overflow with the font scale written to `bodyPr`) with the existing autofit code; Format Shape › Text box exposes Do not autofit / Shrink text on overflow / Resize shape to fit text. Prompt text ("Click to add title") is rendered with the layout placeholder's formatting (size, font, colour, alignment, bullet) and disappears on the first keystroke; empty placeholders keep the prompt in the editor view, never in the show/print/export.
3. **Master and layout text.** In the master/layout view, placeholder text (`lstStyle` levels 1–9 incl. `marL`, `indent`, bullet, size, colour) is edited in place with the same editor; the core gets commands for master/layout text levels 2–9 (today 1 only), **rename layout**, **add placeholder** (title/body/picture/chart/table/footer/date/slide number) and **delete placeholder** on a layout; slides re-render when the master text changes; `layoutText` honours per-level `marL`/`indent` (deferred S item). pptx roundtrip of edited masters/layouts stays clean (harness).
4. **Text box insertion (QA S-14).** Insert › Text box: a click creates a single-line autofit box at the cursor (PowerPoint width 2.5 cm, grows while typing), a drag creates a box with that width and `spAutoFit` height; cursor and in-place editing start immediately. Also: default white text on filled auto shapes via `p:style`/`fontRef` if the writer does not do it yet (check first; skip if already present).
