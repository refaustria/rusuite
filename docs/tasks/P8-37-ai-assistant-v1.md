1. **Provider adapters** (`ui-shared/ai/providers/`): interface `AiProvider { id, name, models(): ModelInfo[], complete(req: { system, messages, maxTokens, temperature, tools?, stream: true }) → AsyncIterable<Delta> (text deltas, tool-use blocks, usage, stop reason) }`; **Anthropic** (Messages API `POST https://api.anthropic.com/v1/messages`, headers `x-api-key`, `anthropic-version: 2023-06-01`, and `anthropic-dangerous-direct-browser-access: true` for browser calls; SSE streaming; tool use for structured outputs; default model `claude-sonnet-5-5`, selectable `claude-opus-5-5`, `claude-haiku-5-5`, plus a free-text model id), **OpenAI-compatible** (`/v1/chat/completions` streaming; base URL configurable – covers OpenAI, Ollama, LM Studio, vLLM; JSON-schema response format where supported); errors mapped to clear messages (401 key, 429 rate limit with retry-after, network/CORS, CSP block).
2. **Settings › AI** (File › Options › AI): enable toggle (off by default), provider, API key (masked, "Test" button that lists models or sends a 1-token request; stored only on the device: desktop app data via the Tauri store; web `localStorage` with the explicit note; never in URLs/logs), base URL for OpenAI-compatible, model, max tokens, temperature, "Include whole document" default off with a size warning, data notice sentence "Text you select is sent to <provider> only when you use an AI action", "Forget key" button; status bar indicator when AI is enabled.
3. **Assistant panel** (right task pane, Ctrl+Shift+A, ribbon Home › AI button in all apps): prompt box with streaming answer, action chips per app, "Insert"/"Replace selection"/"Copy" on results, conversation kept per document session only (not persisted), Stop button, token/usage line, model picker. Context sent = the selection (or the active cell/range/slide) + a short description of the document (title, counts); the whole document only with the toggle.
4. **Actions**: **Write**: Rewrite / Shorten / Expand / Fix grammar & spelling / Change tone (formal, friendly, concise) / Translate (EN↔DE + free language) / Summarize document / Draft from prompt (inserts paragraphs with headings via the normal insert commands, undoable as one step) / Table from text (JSON schema → InsertTable). **Calc**: Formula from description (tool-use schema `{formula, explanation}`; inserts `=…` into the active cell and shows the explanation; validates with the parser before inserting), Explain this formula, Transform range (schema returns a 2-D array of values/formulas for a destination range chosen with the range picker; preview before apply), Chart suggestion (returns a chart kind + ranges → uses the existing chart insert). **Show**: Outline to slides (schema: slides with title/bullets/notes → InsertSlides with the current theme/layouts), Speaker notes for this slide, Rewrite slide text, Suggest a layout (picks from the deck's layouts). Each action has a prompt template with a system prompt that forbids markdown in inserted text where plain text is needed.
5. **Desktop transport**: verify `fetch` to the provider works in the Tauri webviews (CORS: Anthropic allows browser calls with the header above; OpenAI-compatible local servers usually allow); if a provider blocks, route through `tauri-plugin-http` with a scope limited to the configured base URL – still direct to the provider.
