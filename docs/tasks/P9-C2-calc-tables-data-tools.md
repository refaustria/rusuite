## Items (one commit each, with regression tests; up to 5 commits)
1. **Structured references and table styles.** Deleting or renaming a table column rewrites every structured reference to it (`Table1[Col]`, `[@Col]`, `Table1[[#Headers],[Col]]`, ranges `[Col1]:[Col3]`) in formulas, names, CF and validation like Excel (a deleted column's references become `#REF!` only when the column itself is gone, not its neighbours); resizing a table and inserting columns keep references valid. **Custom table styles**: New Table Style… dialog (elements Whole Table, Header Row, Total Row, First/Last Column, First/Second Row Stripe, First/Second Column Stripe with fill/font/border per element, stripe size), stored as `dxf` + `tableStyles/tableStyle` in `styles.xml`, applied through `tableStyleInfo`, listed under "Custom" in the gallery, Modify/Duplicate/Delete/Set as default; built-in gallery previews stay.
2. **Slicers.** Slicers for tables and pivot tables (Insert › Slicer, Table Design › Insert Slicer, PivotTable Analyze › Insert Slicer): model (`slicerCache` + `slicer` parts, `x14` extLst on the sheet, `slicerStyle` built-ins Light/Dark 1–6), a floating slicer object on the grid (items as buttons, multi-select toggle, clear filter, columns/button height, caption), filtering the table's AutoFilter or the pivot's page/row field, connected to several pivots from one cache (Report Connections), roundtrip to xlsx (Excel must open it: validate the part names/relationships against the spec and an openpyxl-free reference – openpyxl cannot write slicers, so build the XML from the ECMA-376 / MS-XLSX documentation and keep our reader strict about what we write). Timelines are out of scope (report).
3. **Flash Fill, Consolidate, Auto Outline.** **Flash Fill** (Data › Flash Fill, Ctrl+E): infer the pattern of the typed examples in the current column from the adjacent columns (Excel's common cases: concatenation with literals, substring by delimiter/position, case changes, number/date reformatting via the existing number-format code), preview greyed suggestions when a second example matches, apply as one undo step; **Consolidate** (Data › Consolidate: function, references with Add/Delete, labels in top row/left column, create links to source data = formulas instead of values); **Auto Outline** (Data › Group ▾ › Auto Outline, Clear Outline) deriving row/column groups from formula summary rows/columns like Excel (Settings: summary rows below/right), using the existing outline model.
4. **Print and desktop.** Page Setup › Sheet: columns to repeat at left (`Print_Titles` with both row and column parts), rows to repeat at top beyond the first rows (any contiguous range), "Print area" with several areas (`Print_Area` union); the print preview and PDF honour them; `.csv` and `.txt` filters in the desktop Open dialog (and the Text Import Wizard opens for them as on the web).
5. **Tests and docs.** Unit tests ≥ 30 (Rust: structured-ref rewrite cases, custom style dxf roundtrip, slicer parts roundtrip and filter application, consolidate math, auto-outline detection; TS: dialogs → commands, Flash Fill pattern inference cases ≥ 10, slicer UI). e2e ≥ 5 on port 4912: delete a table column → dependent formula rewritten; create a custom table style → applied and present after save/reopen; insert a slicer on a table, click an item → rows filtered, saved file reopens with the slicer; Flash Fill splits "First Last" into first names; Auto Outline groups rows under SUM rows.
