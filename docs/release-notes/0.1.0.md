# Rusuite 0.1.0

Rusuite is a small office suite with a Rust core: **Calc** (spreadsheets), **Write** (documents) and **Show**
(presentations). The apps open and save real `.xlsx`, `.docx` and `.pptx` files, run on Windows, macOS and Linux and,
with nothing to install, in your browser.

Rusuite is free and open source (MIT) – and it will stay that way.

**Try it in the browser:** <https://rusuit.es/> – the same apps as the desktop builds (cloud connections and the
AI assistant are desktop-only).

## Highlights
- **Calc** – an Excel-compatible formula engine with 221 functions and dynamic arrays, formula editing by pointing,
  conditional formatting, data validation, sort and filter, Excel tables, PivotTables, charts, comments and printing.
- **Write** – styles, lists, tables, pictures, shapes and text boxes in a print layout with real pages, headers and
  footers, sections and columns, footnotes, table of contents, cross-references, comments, find and replace.
- **Show** – themes and slide masters, 110 shapes, connectors, tables, charts, audio and video, transitions and
  animations, a presenter view and printing of handouts and notes.
- **All apps** – an Office-style ribbon, English and German, undo/redo, autosave with crash recovery, PDF export.

The full list is in [CHANGELOG.md](https://github.com/refaustria/rusuite/blob/main/CHANGELOG.md), with the known
limitations of each app.

| --- | --- |
| Windows 10/11 (x64; the installer adds Microsoft Edge WebView2 if missing) | `…_x64-setup.exe` (installs for your user), `…_x64_en-US.msi` (for administrators) |
| macOS, Apple Silicon (M1 and newer) | `…_aarch64.dmg` |

| Linux x86_64 (Ubuntu 22.04, Debian 12, Fedora 38 or newer) | `…_amd64.deb` (Debian, Ubuntu), `…x86_64.rpm` (Fedora, openSUSE), `…_amd64.AppImage` (any distribution; needs WebKitGTK 4.1) |

There is one set per app (Rusuite Calc, Write, Show). The SHA-256 checksum of every file is shown next to it under
**Assets** and on <https://rusuit.es/downloads.html>.

**These are unsigned builds.** Windows SmartScreen says "Windows protected your PC" – choose *More info › Run anyway*.
macOS says the developer cannot be verified – right-click the app › *Open* › *Open* (or System Settings › Privacy &
Security › *Open Anyway*). This is expected for this release; compare the checksum if you want to be sure the file is
ours.

## Privacy
Your documents never leave your device. The website only serves the program files: no upload, no account, no cookies,
no tracking, no analytics, and a security policy that lets the web apps talk only to their own site. Autosave copies and
recent files stay in your browser (or, on the desktop, in your user account's app folder) and can be removed in
File › Privacy. Cloud connections (WebDAV) and the AI assistant exist only in the desktop apps, are off until you set
them up with your own account, and contact only the server you configured, only when you use them. Details:
<https://rusuit.es/privacy.html>.
