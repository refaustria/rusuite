# Rusuite 3.1415

Rusuite is a small office suite with a Rust core: **Calc** (spreadsheets), **Write** (documents) and **Show**
(presentations). The apps open and save real `.xlsx`, `.docx` and `.pptx` files, run on Windows, macOS and Linux, on
Android and iOS and, with nothing to install, in your browser at <https://rusuit.es/>.

**3.1415** adds the next digit of π (3.141 → 3.1415 → 3.14159 …). This cycle is about reach and trust: the apps are now
**phone and tablet apps**, the desktop installers are **signed**, and every app can **export PDF**. Rusuite is free and
open source (MIT) – and it will stay that way.

## Highlights
- **Phones and tablets** – Calc, Write and Show for Android and iOS, with a compact layout (top bar, bottom command
  bar, bottom sheets) and real touch editing in every app.
- **Signed desktop apps** – see "Signing" below for what is signed on which system.
- **Export as PDF** – in all three apps, on every platform.
- **24 store listings** – the app pages in Google Play and the App Store come in all 24 EU languages the stores accept.

## What's new

### Phones and tablets
- **Google Play and App Store:** Rusuite Calc, Write and Show for Android (8.0 and newer) and iOS (15 and newer) – free, without
  account, advertising or tracking. Play Store: <Play Store link> · App Store: <App Store link>
- **Compact layout:** below 900 px width (phones, narrow windows and the web app on a phone) the ribbon gives way to a top
  bar and a bottom command bar built from the same commands; dialogs and menus open as bottom sheets; targets are at
  least 44 px; the soft keyboard and the notch/gesture areas are respected. Tablets of 900 px and more keep the ribbon.
- **Files:** open `.xlsx`, `.docx`, `.pptx` from the system file picker or with "Open with" from other apps, save back
  to the same document, export and share through the system sheet.
- **Touch editing in Calc:** selection handles, pan versus select, pinch to zoom, a fill handle, a formula keyboard row
  with reference picking, compact formula bar, sheet strip and status chips.
- **Touch editing in Write:** the page fits the width on a phone (double-tap switches to 100 %), long-press selection
  with a floating bar and handles, handles for pictures and tables, a caret that stays above the soft keyboard.
- **Touch editing in Show:** a thumbnail strip, pinch and twist to scale and rotate shapes, a presentation in the same
  window with swipe navigation and an overlay, a Timing sheet for animations.
- **Export as PDF:** File › Export PDF and, on phones, Share as PDF and Print through the system print service.
  On Windows and macOS the desktop apps still open the print dialog (choose "Save as PDF" there); on Linux, Android and
  iOS the PDF is written directly.
- **Languages:** the interface in 24 languages also on the phone, with a compact-layout check at 412 px for each of them.

## Upgrade notes
- **Documents** stay standard `.xlsx`, `.docx` and `.pptx` files; everything made with 3.141 or 0.1.0 opens unchanged.
  Settings, recent files and autosave copies are kept.
- **Windows – installer:** install the new version with the NSIS `…-setup.exe` (an upgrade over 3.141). The **MSI does
  not upgrade 3.141**: Windows Installer compares the first three version fields and the new numbering of the MSI
  (`3.14.15`) is formally lower than `3.141`. If you installed with the MSI, uninstall 3.141 first (Settings › Apps),
  then install the 3.1415 MSI. From 3.1415 on the MSI upgrades normally.
- **macOS:** if the build is signed and notarized (see above), the "Not Opened" warning and the *Open Anyway* step of
  3.141 are gone: open the `.dmg`, drag the app to Applications and start it. You can check it with
  `spctl -a -vv "/Applications/Rusuite Calc.app"` ("accepted, source=Notarized Developer ID").
- **Linux – verify the download (GPG):** the packages come with `.asc` signatures and a signed `SHA256SUMS`.
  ```
  # download SHA256SUMS, SHA256SUMS.asc and your file from the release's Assets, then:
  curl -O https://rusuit.es/rusuite-release-key.asc            # public key; fingerprint on the Downloads page
  gpg --import rusuite-release-key.asc
  gpg --verify SHA256SUMS.asc SHA256SUMS
  sha256sum --ignore-missing -c SHA256SUMS
  gpg --verify <file>.asc <file>                               # a single package
  ```
  The key fingerprint is 8718 41E2 7F18 42D5 C9AD 3271 8489 ACCF 5138 3948.
- **Phones:** the apps install from the stores like any other app; no account is needed to use them.

## Known limitations
- **Not yet tried on hardware:** the phone and tablet apps were built, packaged and checked automatically and in a
  browser with touch emulation; file picker, write-back, sharing, "Open with" and PDF export have not yet been run on a
  real Android or iOS device. Expect rough edges and please report them.
- **Touch:** Write on a phone shows the page fit-width (≈ 49 % at 412 px, readable after a double-tap); Show's pinch
  zooms the slide only in Fit mode; Show's presenter view with a second window is desktop only (phones present in the
  same window); an iOS cold start with a document may need a second "Open" from Files; an export to a provider that
  refuses bookmarks leaves the document untitled (Save asks again).
- **PDF:** on Windows and macOS the desktop PDF export still uses the print dialog; on mobile the print service scales
  to another paper size instead of re-laying out the pages (choose the paper in File › Print first); an exported PDF
  does not enter the recent list.
- **Stores:** Google Play accepts 22 of the 24 listing languages (no Irish, no Maltese) and the App Store 18 (also no
  Bulgarian, Estonian, Lithuanian, Latvian); those stores show the English listing. The apps themselves are fully
  translated.
- **Languages:** native speakers have not yet proof-read the new touch terms in Maltese, Irish, Estonian and Latvian
  (and a few Hungarian and Greek wordings); reports are welcome.
- **Phones:** the AI assistant, cloud connections (WebDAV) and "Report a problem" are desktop features and are hidden on
  Android and iOS.
- **Windows:** the MSI does not upgrade 3.141 (see Upgrade notes).
- **Desktop:** no automatic updates; saving overwrites the file directly and does not warn when it changed on disk.
- **Files:** compatibility is tested against LibreOffice and generated reference files; checks with files made in
  Microsoft Office are done by hand before each release (docs/testing.md). No new file features this cycle; the
  limitations of 3.141 for Calc, Write and Show (see its release notes) still apply.

The full list is in [CHANGELOG.md](https://github.com/refaustria/rusuite/blob/main/CHANGELOG.md).

## Privacy
Unchanged: your documents never leave your device. The website only serves the program files: no upload, no account,
no cookies, no tracking, no analytics, and a security policy that lets the web apps talk only to their own site. The
phone apps collect no data (the store privacy declarations say so). Autosave copies and recent files stay in your
browser (or in the app's folder) and can be removed in File › Privacy. Cloud connections (WebDAV) and the AI assistant
exist only in the desktop apps, are off until you set them up with your own account, and contact only the server you
configured, only when you use them. Details: <https://rusuit.es/privacy.html>.
