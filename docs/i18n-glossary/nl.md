# Glossary: Dutch (`nl`)

Source: Microsoft Office localisation for Dutch (Netherlands) – ribbon tabs, groups and commands of Word, Excel and PowerPoint. Translator: P9-L3. Reviewer: PM.

## Register
- Address: je / jij / jouw / jezelf; never u / uw (the check flags them). Instructions in the familiar imperative ("Kies…", "Geef … op", "Typ…").
- Buttons and menu commands: infinitive as in Office ("Opslaan", "Openen", "Invoegen", "Verwijderen", "Wijzigen"); descriptive sentences in full ("Je wijzigingen gaan verloren…").
- Ellipsis "…" for commands that open a dialog, as in English. Quotes: “…”.
- Keyboard key names in shortcut texts (packages/ui-shared/src/i18n/keyNames.ts): Ctrl = Ctrl, Shift = Shift, Delete = Delete, Enter = Enter (Dutch Office keeps the English key names).
