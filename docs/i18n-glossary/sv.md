# Glossary: Swedish (`sv`)

Source: Microsoft Office localisation for Swedish – ribbon tabs, groups and commands of Word, Excel and PowerPoint. Translator: P9-L3. Reviewer: PM.

## Register
- Address: du / dig / din / ditt / dina; never Ni / Er / Ert / Era. Instructions in the imperative ("Välj…", "Ange…", "Skriv…").
- Buttons and menu commands: imperative/infinitive stem as in Office ("Spara", "Öppna", "Infoga", "Ta bort", "Ändra"); descriptive sentences in full ("Dina ändringar går förlorade…").
- Ellipsis "…" for commands that open a dialog, as in English. Quotes: ”…” (same mark on both sides).
- Keyboard key names in shortcut texts (packages/ui-shared/src/i18n/keyNames.ts): Ctrl = Ctrl, Shift = Skift, Delete = Delete, Enter = Retur.
